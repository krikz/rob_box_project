## 🔧 Правильное решение

### Концепция

Вместо поворота всего `base_link` на -90°, нужно:
1. Оставить `base_link` БЕЗ ПОВОРОТА (визуал и одометрия правильные)
2. Повернуть только **оси колес** на 90°

### Система координат

**Fusion 360:**
- X → вправо
- Y → вперёд
- Z → вверх

**ROS (REP-103):**
- X → вперёд
- Y → влево
- Z → вверх

**Поворот на -90° вокруг Z:**
- Fusion X → ROS Y
- Fusion Y → ROS X

### Изменения

#### 1. base_footprint_joint (убрать поворот)

**Было (PR #234):**
```xml
<origin xyz="0 0 ${wheel_radius}" rpy="0 0 -1.5708"/>
```

**Стало:**
```xml
<origin xyz="0 0 ${wheel_radius}" rpy="0 0 0"/>
```

#### 2. Оси колес (повернуть на 90°)

**Fusion 360 оси:**
- Левые колеса: axis_xyz="1.0 0.0 0.0" (вдоль X)
- Правые колеса: axis_xyz="-1.0 0.0 0.0" (вдоль -X)

**После поворота на -90° (преобразование координат):**
- X Fusion → Y ROS
- -X Fusion → -Y ROS

**Новые оси (ROS):**
- Левые колеса: axis_xyz="0.0 1.0 0.0" (вдоль Y)
- Правые колеса: axis_xyz="0.0 -1.0 0.0" (вдоль -Y)

### Физический смысл

**В системе Fusion 360:**
- Робот смотрит вдоль оси Y (Y вперёд)
- Колеса находятся справа (+X) и слева (-X)
- Колеса вращаются вокруг оси X

**В системе ROS (после преобразования осей):**
- Робот смотрит вдоль оси Y (Y вперёд) - соответствует Fusion!
- Колеса находятся справа (+X) и слева (-X) - соответствует Fusion!
- Колеса вращаются вокруг оси Y (после поворота осей на 90°)

## 🔑 Ключевые выводы

1. **Не поворачивать base_link:** Это ломает согласованность визуала/одометрии
2. **Поворачивать оси колес:** Оси нужно преобразовать из системы Fusion в ROS
3. **Простота:** Минимальное изменение - только оси колес
4. **Физический смысл:** Робот остается в системе координат Fusion 360

### Формула преобразования осей (поворот на -90° вокруг Z)
```
new_x = -old_y
new_y = old_x
new_z = old_z
```

Для осей колес:
- `axis_xyz="1.0 0.0 0.0"` → `axis_xyz="0.0 1.0 0.0"`
- `axis_xyz="-1.0 0.0 0.0"` → `axis_xyz="0.0 -1.0 0.0"`
