🎛️ PRODUCTION QUALITY — TECHNIQUES FROM PRO LIVE CODERS:
These are what separates good music from noise. USE THEM in every track!

┌─ 1. VOLUME DUCKING (makes club music "breathe"):
│  ❌ Do NOT use chop= — on 16 kHz hardware it creates audible clicks!
│  ✅ Use amplify=var([1,0.3],[0.5,0.5]) for volume-based ducking instead:
│  ✅ d1 >> play("X..X.o..", sample=1, amp=0.18)
│     p1 >> pads([0,2,4], dur=4, amp=0.18, amplify=var([1,0.3],[0.5,0.5]))
│     p2 >> dub([0,-2], dur=2, oct=3, amp=0.28)
│  The amplify=var() creates the "pump" without clicking artifacts.

├─ 2. BASS MIRRORS MELODY (fundamental harmony rule):
│  Bass MUST play the same chord tones as the lead, just one octave lower!
│  ✅ p1 >> arpy([0,2,4,2], dur=0.5, oct=5, amp=0.6)   # lead: oct=5
│     p2 >> dub([0,2,4,2], dur=2, oct=3, amp=0.35)      # bass: SAME degrees, oct=3
│  ❌ Bass playing random [0,-2,3] while lead plays [0,2,4,7] = dissonance!

├─ 3. MASTER FILTER (one variable controls multiple layers simultaneously):
│  Define ONE linvar and apply it to HPF of multiple instruments at once:
│  ✅ flt = linvar([200, 4000], 32)
│     p1 >> arpy([0,2,4,7], dur=0.5, oct=5, amp=0.6, hpf=flt)
│     p2 >> dub([0,-2], dur=2, oct=3, amp=0.35, hpf=flt)
│     p3 >> pads([0,2,4], dur=4, amp=0.2, hpf=flt)
│  This creates a unified filter sweep across the whole mix.

├─ 4. DROP / BREAK TECHNIQUE (tension and release):
│  Use amplify=var([1,0],[28,4]) for 28-bar groove → 4-bar silence before drop:
│  ✅ d1 >> play("X..X.o..", sample=1, amp=0.25, amplify=var([1,0],[28,4]))
│     p1 >> arpy([0,2,4,7], dur=0.5, amp=0.6, amplify=var([1,0],[28,4]))
│  Or HPF buildup before drop: gBeats.hpf = linvar([0,5000],[12,0], start=Clock.mod(4))

├─ 5. SWING / GROOVE on hi-hats (human feel, not robotic):
│  Add micro-timing delay for organic groove. Use SPARSE patterns, not continuous "--------"!
│  ✅ d2 >> play("--.-", dur=1, sample=3, amp=0.1,
│               delay=PRand([0, PWhite(-0.1, 0.1)]))
│  ❌ d2 >> play("--------", dur=0.5, ...) — too dense, causes clicking on 16kHz hardware!
│  This is the #1 difference between stiff and groovy drumming!

├─ 6. FOLLOW() — AUTOMATIC HARMONY (pads follow bass):
│  Instead of hardcoding pad chords, let them auto-harmonize over bass:
│  ✅ p1 >> dub([0,4,5,3], dur=4, oct=3, amp=0.35)      # bass defines chords
│     p2 >> pads(dur=4, amp=0.2, room=0.6).follow(p1) + (0,2,4)  # pads auto-follow
│     p3 >> arpy(dur=0.5, amp=0.5, oct=6).follow(p1)     # lead auto-follows too
│  Changing p1 chord automatically updates ALL harmony!

├─ 7. VOCAL CHOPS / GLITCH (striate for sliced samples):
│  ONLY use this when user EXPLICITLY asks for chopped / glitch / sliced vocals.
│  Default party request "добавь вокал" ≠ glitch chops.
│  ✅ d3 >> play("c", sample=4, spack=1, striate=8, dur=4, sus=4, amp=0.16)
│  Keep chopped vocals LOW in the mix: amp 0.12-0.18, max ONE vocal layer.
│  Never use striate vocals as the loudest element in the track.

└─ 8. USE SPECIFIC NOTE SEQUENCES, not all-PRand:
   ✅ p1 >> arpy([0,2,4,2,3,1,3,1], dur=0.25, oct=5, amp=0.6)  ← intentional melody
   ❌ p1 >> arpy(PRand([0,2,4,5,7]), dur=0.25, amp=0.5)          ← sounds random/weak
   Use PRand ONLY for variation at end of a sequence or for occasional note:
   ✅ p1 >> arpy([0,2,4,2, PRand([3,5,7]),2,1,0], dur=0.25, amp=0.6)
