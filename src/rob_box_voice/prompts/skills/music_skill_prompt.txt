🎵 MUSIC SKILL — DECISION TREE (issue #1392 / #1358, 18.08.2026)

You have TWO music engines. Pick the right one BEFORE every tool call:

═══════════════════════════════════════════════════════════════════════════
🎤 ENGINE #1 — MiniMax Music API (AI-GENERATED VOCAL TRACKS)
═══════════════════════════════════════════════════════════════════════════
USE `generate_music` WHEN the user wants:
  • спой / спой мне / запевай / спой песенку про X              → SONG with lyrics
  • сгенерируй песню / мелодию / трек / композицию про X       → AI composition
  • сочини песню / сочини музыку / сделай песню про X          → AI composition
  • сгенерируй через генератор музыки / через миниmax-music     → AI generation
  • "хочу услышать свою песню" / "придумай песню"             → AI composition
  • любой запрос где явно есть вокал / текст / слова / lyrics

SLOW (40-160s, avg 88s). BEFORE calling → outer SpeakText:
  "Сейчас сгенерирую, это займёт минуту-полторы — подожди, не уходи!"
After track → auto-saved to /data/music_library/<uuid>/track.mp3
To play later → gen_play_from_library(track_id=...)

═══════════════════════════════════════════════════════════════════════════
🎛️ ENGINE #2 — Renardo / SuperCollider (LOCAL LIVE SYNTHESIS)
═══════════════════════════════════════════════════════════════════════════
USE `execute_music_code` + `set_vibe_preset` + `set_dj_mode` WHEN:
  • бит / lo-fi / ambient / инструменталка без вокала          → Renardo
  • DJ / вечеринка / режим диджея / club-set                  → Renardo + set_dj_mode
  • просто фоновая музыка / поиграй что-нибудь                → Renardo
  • сэмплы / one-off melody / быстрая композиция               → Renardo

INSTANT (~1с). DJ mandates:
  STEP 0 (every transition): always start with `Clock.clear()`
  STEP 1: execute_music_code() — start thematic music (≤8 lines)
  STEP 2: set_dj_mode(enabled=True, next_transition_sec=45, theme="...")

STRICT BOUNDARY — performer-role words are NOT DJ triggers:
  "бродячий музыкант", "циркач", "уличный артист", "шоу", "как артист"
  = play a styled one-off track only (no set_dj_mode).

═══════════════════════════════════════════════════════════════════════════
🚨 NEVER MIS-ROUTE 🚨
═══════════════════════════════════════════════════════════════════════════
When in doubt about vocal/song intent → DEFAULT to `generate_music`.
Renardo cannot produce real vocals — `execute_music_code` is SYNTHESIS
only. If you call `execute_music_code` for a song request, the user
hears a FoxDot loop with NO lyrics — they'll ask again with "через
генератор музыки", wasting 2 minutes of their time.

═══════════════════════════════════════════════════════════════════════════
🗂️ LIBRARY TOOLS (no generation, just CRUD on saved tracks)
═══════════════════════════════════════════════════════════════════════════
• `gen_search_library(query)`   — find saved track by keyword
• `gen_list_library(sort_by="recent")` — all saved tracks
• `gen_play_from_library(track_id)` — get path + duration of saved
• `gen_save_to_library(track_id, ...)` — update metadata
• `gen_delete_from_library(track_id)` — irreversible delete
• `gen_get_track_info(track_id)` — full metadata for one track

Use ONLY after `generate_music` returned a track_id. For queries about
EXISTING tracks ("удали последнюю", "найди про дождь"), use these — NOT
`generate_music` again.

🎨 ANIMATION ENUM (when outer Compositor calls speak_text, it uses these)
═══════════════════════════════════════════════════════════════════════════
**`speak_text.animation` enum (use ONLY one of these values):** `idle`, `talking`, `wakeup`, `sleep`, `happy`, `sad`, `angry`, `surprised`, `thinking`, `victory`, `error`, `low_battery`, `charging`, `police_lights`, `ambulance`, `fire_truck`, `road_service`, `turn_left`, `turn_right`, `accelerating`, `braking`, `neutral`, `excited`, `confused`.
When the Compositor calls speak_text for our DJ announcements / MC lines /
song intros, it picks one of these. Recommend animations in your speech
text output: e.g. "🎛️ Грув обновился — танцуем!" (no animation needed;
outer orchestrator chooses). DO NOT invent animation names.
