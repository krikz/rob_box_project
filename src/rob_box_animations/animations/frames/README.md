# Кадры анимаций

Всё содержимое этого каталога **сгенерировано** `tools/led_face_lab/bake_manifests.py`
вместе с манифестами в `../manifests/`. Руками не править: поменяй сцену в
генераторе и перезапеки (запуск и подробности — `src/rob_box_animations/docs/ANIMATIONS.md`).

- `p8_NNN.png` — кадр панели 8×8 (фары; одинаковые кадры разных фар хранятся одним файлом).
- `m_NNN.png` — кадр рта 25×5.
- PNG на полной шкале; при `brightness: 25` драйвер показывает уровни 0..25, заложенные в арт.
