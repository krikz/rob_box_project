# led_matrix_driver

Низкоуровневый ROS 2 драйвер для LED-матрицы Rob Box: WS2812B NeoPixel через SPI.

## Описание

Пакет реализует SPI-драйвер для управления 381 NeoPixel RGB LED: 4× матрицы 8×8 (фары/headlights) + 1× матрица 5×25 (основной дисплей). Нода принимает пиксельные данные в ROS 2 топик и отправляет их на светодиоды через SPI интерфейс.

Анимации и высокоуровневое управление реализованы в пакете `rob_box_animations`.

## Нода

**`led_matrix_simple`** — основная нода-драйвер.

## Топики

| Топик | Тип | Направление | Описание |
|-------|-----|-------------|---------|
| `led_matrix/data` | `std_msgs/ByteMultiArray` | Подписка | Пиксельные данные (3 байта на LED: R, G, B) |

Топик конфигурируется параметром `input_topic`.

## Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|---------|
| `num_leds` | `253` | Количество LEDs (реально: 381) |
| `spi_speed_khz` | `1300` | Скорость SPI шины в кГц |
| `spi_device` | `/dev/spidev0.0` | Путь к SPI устройству |
| `input_topic` | `led_matrix/data` | ROS 2 топик пиксельных данных |

> **Примечание**: Параметр `num_leds` по умолчанию = 253, реальное количество LED на роботе = 381. Для полной матрицы установите `num_leds: 381` в конфигурационном файле.

## Конфигурация

Параметры задаются через YAML в `config/`:

```bash
# Просмотр конфигурации
cat docker/vision/config/led_matrix.yaml
```

## Запуск

Запускается в Docker контейнере `led-matrix` на Vision Pi:

```bash
# Статус
docker logs led-matrix -f

# Перезапуск
docker compose -f docker/vision/docker-compose.yaml restart led-matrix
```

## Зависимости

- `rclpy` — ROS 2 Python клиент
- `std_msgs` — стандартные ROS 2 сообщения
- `spidev` (Python) — SPI интерфейс
- `rob_box_animations` — высокоуровневое управление анимациями
