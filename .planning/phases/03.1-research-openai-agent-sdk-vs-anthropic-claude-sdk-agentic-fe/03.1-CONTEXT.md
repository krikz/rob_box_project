# Phase 03.1: Research OpenAI Agent SDK vs Anthropic Claude SDK - Context

**Gathered:** 2026-06-12
**Status:** Ready for research

<domain>
## Phase Boundary

Провести глубокое сравнительное исследование агентских возможностей OpenAI SDK + Agents SDK и Anthropic Claude SDK. Цель — понять что изменилось в OpenAI после апгрейда в PR #837 (openai>=2.37.0) и какие фичи появились в Anthropic, чтобы определить что применимо для Rob Box (dialogue_node, telegram-бот, автономный агент).

Результат: RESEARCH.md с фича-матрицей, анализом изменений и рекомендациями.
</domain>

<decisions>
## Implementation Decisions

### Scope — Что сравниваем (весь стек)
- **D-01:** Полный стек обоих вендоров: от низкоуровневого SDK (chat completions) → agents framework → tools/MCP → sandbox/workspace → voice/realtime
- **D-02:** OpenAI: `openai` SDK (v2.37.0 → v2.41.1 changes) + `openai-agents` SDK (v0.17.x features)
- **D-03:** Anthropic: `anthropic` Claude SDK (v0.109.x) + Managed Agents + Claude Code паттерны

### Decision Criteria — Критерии оценки
- **D-04:** **Multi-provider поддержка** (критично): возможность работать через DeepSeek/Qwen API, а не только родные OpenAI/Anthropic
- **D-05:** **Voice + Realtime**: голосовой агентский пайплайн (STT → Agent → TTS), применимость к dialogue_node
- **D-06:** **Sandbox + Workspace**: изолированные агенты с ФС для долгих задач (анализ кода, генерация, патчи)
- **D-07:** **Агентские циклы (agent loops)**: как организованы, какие подходы практичнее — архитектура, управление состоянием, обработка ошибок, barge-in/interrupt
- **D-08:** Сравнить по всем измерениям, дать рекомендацию что применимо для Rob Box

### Output — Результат
- **D-09:** Полный RESEARCH.md: (1) фича-матрица, (2) анализ изменений OpenAI SDK, (3) разбор Anthropic, (4) сравнение, (5) рекомендации для Rob Box

### Depth — Глубина исследования
- **D-10:** Глубокое исследование: релиз-ноты + документация + примеры кода + тестирование совместимости с DeepSeek API
- **D-11:** Проверять совместимость каждой ключевой фичи с DeepSeek (base_url, tool calling, streaming, agents)

### Фокус: агентские циклы
- **D-12:** Особое внимание — как организованы agent loops в обоих SDK:
  - OpenAI Agents SDK: Runner → Agent → Model → Tools → цикл до completion
  - Anthropic: messages API + tool_use + Managed Agents multi-agent orchestration
  - Сравнить: управление историей, обработка ошибок, прерывания (barge-in), parallel tool calls

### the agent's Discretion
- Формат RESEARCH.md — на усмотрение исследователя (должен быть читаемым и практичным)
- Какие примеры кода приводить — релевантные для dialogue_node и telegram-бота
- Порядок секций в RESEARCH.md

</decisions>
