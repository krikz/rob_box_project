### Task 1: Improved error handling in dialogue_node.py ✅

**Before (v1.101.0):**
```python
from openai import APIConnectionError, AsyncOpenAI
# только один тип ошибки ловился
except APIConnectionError as exc:
    ...
```

**After (v2.x):**
```python
from openai import APIConnectionError, APITimeoutError, APIStatusError, RateLimitError, AsyncOpenAI

except APITimeoutError as exc:       # ⏰ таймаут → fallback на flash-модель
except RateLimitError as exc:        # 🔄 429 → ждать retry-after
except APIStatusError as exc:        # 🌩️ 5xx → retry с backoff
except APIConnectionError as exc:    # 📡 WiFi → retry с backoff
```

### Task 1b: Fallback model on timeout ✅

- New ROS param: `fallback_model` (default: `deepseek-v4-flash`)
- New ROS param: `enable_fallback` (default: `false`)
- On `APITimeoutError`: if `enable_fallback=true` and fallback model ≠ current → rebuild agent with flash model → retry once
- `_build_agent(model_override=...)` — accepts optional model override

### Task 2: OPENAI_LOG for debugging ✅

- `docker/vision/docker-compose.yaml`: `OPENAI_LOG=info` in voice-assistant env

## How to enable fallback

```yaml
# docker/vision/config/voice_assistant/voice_assistant.yaml
model: "deepseek-v4-pro"
fallback_model: "deepseek-v4-flash"
enable_fallback: true  # ← включить авто-переключение при таймауте
```
