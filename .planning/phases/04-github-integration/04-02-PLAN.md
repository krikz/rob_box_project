| dev-машина → GitHub API | gh CLI отправляет API-запросы к github.com, создаёт labels и milestones |
| gh auth token → GitHub | Token хранится локально в gh keychain; имеет права write на репо |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-02-01 | Enumeration | Label names | accept | Labels публичны в открытом репо; имена labels (type:security, type:stub) не раскрывают секреты системы |
| T-04-02-02 | Spoofing | gh auth token | mitigate | Token не логировать, не выводить в консоль; использовать `gh auth status` для проверки наличия токена до запуска команд |
| T-04-02-03 | Denial of Service | gh api rate limits | accept | Создание 17 labels + 3 milestones << 5000 запросов/час; rate limit не достигается |
</threat_model>
