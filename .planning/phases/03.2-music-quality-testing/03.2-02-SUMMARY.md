### Task 1: Fix compositor_prompt.txt
**File**: `src/rob_box_voice/prompts/compositor_prompt.txt`

1. **MC Phrase Limit** — Added DJ TRANSITION MC RULE: max 1-2 speak_text per transition
   - Prevents 5-6 phrases per transition (observed in logs)
   - ONE short announcement per transition

2. **"done" is PLAIN TEXT ONLY** — Added explicit wrong behavior examples
   - speak_text("done") is a BUG — "done" is a TERMINATOR, not speech

3. **Rap Double-Speak Prevention** — Added RAP DOUBLE-SPEAK BUG rule
   - After handle_music(stop), next response = "done"
   - Prevents MiMo from re-reading rap lyrics from history

### Task 2: Fix dialogue_node.py
**File**: `src/rob_box_voice/rob_box_voice/dialogue_node.py`

2. **Add DJ empty response retry** — is_dj_context check
   - Checks if music tools were recently used

3. **Add frequency_penalty/presence_penalty** — in extra_body

   - presence_penalty=0.2 — encourages variety
