## Key Insight: Why Tracks Are Identical

Root cause analysis:
1. `music_skill_prompt.txt` строка 659-740: "KNOWN MELODY LIBRARY" содержит ТОЛЬКО Imperial March (~80 строк)
2. Все STYLE EXAMPLES A-F (строки 104-175) структурно одинаковые: `d1/d2/p1/p2/p3`
3. Star Wars / Darth Vader инструкции biasят модель
4. MiMo видит только один "известный" паттерн → генерирует вариации одной темы

**Fix**: Replace with diverse presets in library, remove from prompt.
