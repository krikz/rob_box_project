Implementation requirements:
1. **Subclass:** `class ROS2Transport(BaseTransport)` — inherits from BaseTransport which extends Transport with subscribe/unsubscribe helpers.
2. **Constructor:** `__init__(self, node: rclpy.node.Node)` — takes an rclpy Node for creating subscriptions. Store the node reference. NO I/O in __init__.
3. **Lifecycle:** `async def init(self)` — create ROS2 subscriptions here. Subscribe to:
   - `/voice/stt/result` (String msg) → callback routes to `self._on_stt_result(msg)`
   - `/audio/vad` (String msg) → callback routes to `self._on_vad(msg)`
   - Use rclpy QoS: `qos_profile=rclpy.qos.qos_profile_sensor_data` for STT, `qos_profile_system_default` for VAD
4. **Sync→Async bridge:** Each ROS2 callback uses `asyncio.run_coroutine_threadsafe(self._handle_async_event(...), self._event_loop)` to bridge from sync ROS2 callback to async harness methods. The harness passes its event loop via `set_event_loop(loop)` or via init parameter.
5. **teardown:** `async def teardown(self)` — destroy all ROS2 subscriptions. Idempotent (check flag, safe to call multiple times).
6. **imports:** Wrap rclpy imports in try/except ImportError for environments without ROS2 (tests use FakeTransport, not ROS2Transport). Set a flag `ROS2_AVAILABLE = True/False`.
7. **Export:** Add `from .ros2_transport import ROS2Transport` in the transport package `__init__.py`. Create `__init__.py` if it doesn't exist.

Minimum methods:
- `ROS2Transport.__init__(node)` — store node, set _initialized=False
- `ROS2Transport.init()` — create ROS2 subs, set _initialized=True
- `ROS2Transport.teardown()` — destroy subs, set _initialized=False
- `ROS2Transport._on_stt_result(msg)` — ROS2 callback, bridge to async
- `ROS2Transport._on_vad(msg)` — ROS2 callback, bridge to async
- `ROS2Transport._handle_async_event(event)` — async handler that calls super().on_user_input() or on_event()

Create `src/rob_box_harness/rob_box_harness/memory/sqlite_voice.py` implementing the MemoryStore ABC with SQLite persistence.

Implementation requirements:
1. **Subclass:** `class SQLiteVoiceMemory(MemoryStore)` — implements all 4 abstract methods.
2. **Constructor:** `__init__(self, db_path: str = "~/.rob_box/voice.db")` — expand ~ to home dir. Store path. NO file I/O in __init__.
3. **init():** `async def init(self)` — create/connect to SQLite database using aiosqlite (or sqlite3 with asyncio wrapper). Create tables if not exist:
   ```sql
   CREATE TABLE IF NOT EXISTS turns (
       id INTEGER PRIMARY KEY AUTOINCREMENT,
       scope TEXT NOT NULL,
       role TEXT NOT NULL,
       content TEXT NOT NULL,
       name TEXT,
       tool_call_id TEXT,
       metadata_json TEXT,
       created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
   );
   CREATE TABLE IF NOT EXISTS facts (
       id INTEGER PRIMARY KEY AUTOINCREMENT,
       key TEXT NOT NULL,
       value TEXT NOT NULL,
       scope TEXT NOT NULL,
       metadata_json TEXT,
       created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
   );
   CREATE INDEX IF NOT EXISTS idx_turns_scope ON turns(scope, created_at);
   CREATE INDEX IF NOT EXISTS idx_facts_scope_key ON facts(scope, key);
   ```
4. **load_recent(scope, limit=20):** `SELECT role, content, name, tool_call_id, metadata_json FROM turns WHERE scope = ? ORDER BY created_at DESC LIMIT ?` — return list[Turn] in chronological order (reverse the DESC result).
5. **append_turn(scope, turn):** INSERT into turns. Idempotent: check for duplicate before insert (same scope+role+content within last 5 seconds). Return bool (True if inserted, False if duplicate).
6. **save_fact(scope, fact):** INSERT OR REPLACE into facts based on (scope, key). If key already exists for scope, update value.
7. **search_facts(scope, query, top_k=5):** Simple LIKE-based search: `SELECT key, value, metadata_json FROM facts WHERE scope = ? AND (key LIKE ? OR value LIKE ?) LIMIT ?` with `%query%` wildcards. Return list[Fact].
8. **teardown():** `async def teardown(self)` — close DB connection. Idempotent.
9. **Export:** Add `from .sqlite_voice import SQLiteVoiceMemory` in memory `__init__.py`. Create `__init__.py` if it doesn't exist.

Design decisions:
- Use `aiosqlite` for async SQLite access if available, fall back to synchronous sqlite3 with `asyncio.to_thread` for blocking operations
- Turn.metadata and Fact.metadata stored as JSON strings in metadata_json column
- search_facts uses simple LIKE — no semantic embedding for P0 (P1 enhancement)
