Rewrite dialogue_node.py from scratch as a thin ROS2 shell. DELETE all logic that moved to harness ports. KEEP only ROS2-specific code.

**What stays (ROS2 shell, ~250-300 lines):**

1. **ROS2 Node boilerplate** (~30 lines):
   - `class DialogueNode(Node)` — inherits rclpy.node.Node
   - `super().__init__("dialogue_node")`

2. **ROS2 Parameters** (~30 lines):
   - provider, api_key, base_url, model, temperature, max_tokens
   - system_prompt_file, history_max_turns, agent_max_turns
   - dialogue_timeout, wake_words, enable_mcp_tools
   - llm_timeout_sec, verbose_llm, history_excluded_tools

3. **ROS2 Pub/Sub** (~40 lines):
   - `/voice/stt/result` subscriber → delegates to DialogCore.process_input()
   - `/audio/vad` subscriber → tracks speech flag
   - `/voice/dialogue/response` publisher
   - `/voice/dialogue/state` publisher
   - `/voice/sound/trigger` publisher
   - `/voice/tts/control` publisher
   - `/voice/tts/finished` subscriber → release speak_text awaiter
   - `/voice/sound/state` subscriber → release play_sound awaiter
   - `/voice/dj_mode` subscriber

4. **Async loop driver** (~40 lines):
   - Bounded ThreadPoolExecutor (1 worker, per existing pattern)
   - `asyncio.new_event_loop()` + `loop.run_forever()` in executor
   - `shutdown_asyncio_loop()` with timeout

5. **DialogCore composition** (~40 lines):
   - `self._core = DialogCore(llm=DeepSeekProvider(...), tools=ROSMCPToolProvider(...), memory=SQLiteVoiceMemory(...), dsm=DialogueStateMachine())`
   - STT callback → `self._core.process_input(text, history)`
   - Publish response via `/voice/dialogue/response`

6. **DJ mode** (~80 lines):
   - `_dj_mode_enabled`, `_dj_transition_count`, `_dj_theme`, `_dj_set_plan`, `_dj_persona`
   - `_on_dj_mode_msg()` — handle DJ mode commands from MCP
   - `_on_dj_tick_check()` — 5-second auto-transition timer
   - `_build_dj_prompt(n)` — construct DJ transition prompt

7. **Barge-in / cancel** (~30 lines):
   - `_cancel_run(reason)` — cancel async task, flush TTS, release events

8. **Lifecycle** (~20 lines):
   - `destroy_node()` → shutdown async loop
   - `main(args=None)` → rclpy.init, spin, shutdown

**What gets DELETED (moved to harness):**
- `_build_agent()` → DeepSeekProvider
- `_make_tools()` → ToolRegistry
- `_make_output_tools()` → ToolRegistry

- `_truncate_history_outputs()` → MemoryStore
- `_speak_direct()` → TTS effect in SideEffectBus
- `_split_into_chunks()` → utility (keep or move to utils)
- `PROVIDERS` class attribute → deleted
- All `@function_tool` decorators → deleted
- All `async def` tool implementations → deleted
