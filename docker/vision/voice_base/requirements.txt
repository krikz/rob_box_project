# Machine Learning (PyTorch for Silero TTS)
# CRITICAL: PyTorch 2.9.0+ required for ARM64 compatibility!
# PyTorch 2.1.0 has broken MKLDNN matmul primitives on aarch64
# PyTorch 2.9.0 fixes: "could not create a primitive descriptor for a matmul primitive"
# scipy: Required by Silero v5 for audio resampling and processing
#
# Issue #2609 — must pin the CPU-only aarch64 wheel.
# On a `pip install torch>=2.13.0` resolver picks `torch==2.14.0+cu130` (the
# CUDA-13.0 build for x86_64+arm64 with NVIDIA stack). On Vision Pi 5 (no
# GPU, no NVIDIA libs) this pulls in libtorch_cuda.so / libc10_cuda.so /
# libnvpl_blas_*.so / libarm_compute*.so — ~1.6 GiB of useless CUDA binaries
# that bloat RSS by ~800 MB per torch-using node (tts_node + speaker_id_node
# = ~1.6 GiB мёртвого груза, OOM kill в 4 GB voice-assistant mem_limit).
#
# `--extra-index-url https://download.pytorch.org/whl/cpu` ДОБАВЛЯЕТ CPU-канал
# рядом с PyPI. Именно `--extra-index-url`, а НЕ `--index-url`: последний —
# глобальная опция pip, она заменяет PyPI целиком для ВСЕГО файла (независимо
# от того, на какой строке стоит), и тогда с pytorch-индекса начали бы искаться
# vosk / resemblyzer / renardo-lib / ddgs / yandex-cloud-ml-sdk / pyaudio и
# прочие — их там нет, build падает на `No matching distribution found`.
# Оба Dockerfile ставят файл одной командой `pip3 install -r requirements.txt`,
# так что область действия опции — весь список.
#
# Пин ТОЧНЫЙ (`==2.14.0+cpu`), а не диапазон: с двумя индексами под
# `>=2.14.0+cpu,<3.0.0` подходит и PyPI'шный `2.14.0` (это и есть +cu130-сборка
# для aarch64), и resolver волен взять его — вся экономия пропадает. Local
# version label `+cpu` существует только на pytorch-индексе, поэтому точный пин
# однозначно выбирает CPU-wheel: `torch.version.cuda is None`.
#
# Наличие колёс проверено на индексе (2026-09-16):
#   torch-2.14.0+cpu-cp310-cp310-manylinux_2_28_aarch64.whl
#   torchaudio-2.11.0+cpu-cp310-cp310-manylinux_2_28_aarch64.whl
# (база ROS2 Humble / Ubuntu 22.04 = cp310).
#
# Замер до пина (2026-09-15, dev-87f3818): tts_node RSS 866 MB, из них ~800 MB
# — libtorch_cuda.so / libc10_cuda.so / libnvpl_blas_* / libarm_compute*.
