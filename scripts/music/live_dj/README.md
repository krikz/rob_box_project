# Харнессы живого замера DJ-сета (ADR-0149 §7, PR-0)

Скрипты, которыми 30.09–01.10 мерили DJ-режим `rob_box_music` на живом роботе. Раньше лежали вне git
(`artifacts_live_check_2026-09-30/`, `…-10-01/`); перенесены, чтобы приёмку v2 (ADR-0149 §7) можно было повторить
теми же руками. Код робота они не трогают.

## Что есть

## Как запускать

Хост (Windows/Linux): `pip install numpy scipy`, на Windows обязательно `PYTHONUTF8=1` (русский вывод).
Скрипты импортируют друг друга (`import audit_wav as A`), поэтому запускать из этой папки:

```bash
cd scripts/music/live_dj
PYTHONUTF8=1 python compare.py ref_dj_16k.wav --chunk 60 --from 0 --to 600
PYTHONUTF8=1 python accept.py runs/r1.wav runs/r2.wav
PYTHONUTF8=1 python tracks.py runs/set2.full.log runs/r2.wav 2026-10-01T14:24:43Z
```

Серия на роботе (Vision Pi `ros2@10.1.1.21`, пароль в README харнесса не хранится; см. политику доступа в проекте):

```bash
scp scripts/music/live_dj/runs.sh ros2@10.1.1.21:/tmp/cc_runs.sh
ssh ros2@10.1.1.21 'nohup bash /tmp/cc_runs.sh /tmp/runs_v2 >/dev/null 2>&1 &'
# ~32 минуты. Забрать:
scp -r ros2@10.1.1.21:/tmp/runs_v2 ./runs_v2
```

Скрипт сам работает через `docker exec voice-assistant` / `docker exec supercollider`. Перед серией: `music_master_gain 0.5`,
стенд свободен (серия занимает единственный стенд ~30 минут). Если сеть другая, ходить через katana (см. заметки по SSH).

## Какие метрики годятся для приёмки (ADR-0149 §7.2), какие нет

Годятся: тишина (A1), размах RMS по минутам (A6), пик/клипы (A7), стерео — LR, L−R, Side/Mid (A8), баланс полос (A9),
crest (A10), bpm как жанровое окно (A5; помнить диапазон поиска 100–140), онсеты/с как коридор; по логу —
задержки, число вызовов LLM на переходе, охват сэмплов, разнообразие каркасов.

**НЕ годятся как критерий качества** (эпик #3312, `lessons_music_dj.md` §5):

- **R, «захват сетки 16-х».** У живого диджея R = 0.33 на 16 кГц, у робота без сэмплов 0.6–0.86 («механически ровно»).
  Высокий R — не «хорошо». Только диагностика регресса на одном seed.
- **Доля энергии «вне лада».** У эталона 0.28–0.31, у робота 0.10–0.34. Хромаграмма живого микса с перкуссией и
  вокалом «вне лада» по определению. Гармонию мерить по модели трека (key_fit партий), не по записи.
- **Тональность по записи** (колонка «тон.») — у эталона прыгает каждую минуту.
- **«Подходит ли настроение темы»** — только слух Шифу, слепой A/B (ADR-0149 §7.3).

Все числа — необходимое условие, не достаточное: приёмку закрывает слепой A/B на слух.
