## 3. КОЛЕСА И ПОДВЕСКА

### 3.1. Структура

#### Fusion 360 (простая)
```
base_link
├── wheel_rear_left_1    [continuous joint, axis="1 0 0"]
├── wheel_front_left_1   [continuous joint, axis="1 0 0"]
├── wheel_front_right_1  [continuous joint, axis="-1 0 0"]
└── wheel_rear_right_1   [continuous joint, axis="-1 0 0"]
```

#### Текущий URDF (сложная, с подвеской)
```
base_link
├── left_rocker  [fixed joint]
│   ├── left_front_wheel  [continuous joint, axis="0 1 0"]
│   └── left_rear_wheel   [continuous joint, axis="0 1 0"]
└── right_rocker [fixed joint]
    ├── right_front_wheel [continuous joint, axis="0 1 0"]
    └── right_rear_wheel  [continuous joint, axis="0 1 0"]
```

**Критические различия:**
1. **Рокеры:** Fusion 360 НЕ моделирует подвеску! ❌
2. **Ось вращения:** Fusion использует X-ось, текущий - Y-ось ❌
3. **Направление оси:** Fusion инвертирует для правых колес ✅ (правильно)

### 3.3. Wheelbase и Track

#### Fusion 360
```
Wheelbase (Y, front to rear):
  Left:  0.143797 - (-0.145731) = 0.289528 м (~289 мм) ✅
  Right: 0.143797 - (-0.144669) = 0.288466 м (~288 мм) ✅

Track (X, left to right):
  Front: 0.195 - (-0.195967) = 0.390967 м (~391 мм) ✅
  Rear:  0.195 - (-0.195)    = 0.390000 м (~390 мм) ✅
```

#### Текущий URDF (через рокеры)
```
Wheelbase (Y через rockers):
  Left:  0.18048 - (-0.18048) = 0.36096 м (~361 мм) ❌ (+72 мм)
  
Track (X, между передними колесами):
  Между рокерами на Y: 2 × 0.18048 = 0.36096 м ❌
  (должно быть wheelbase, а не track!)

Wheelbase (X, вдоль рокера):
  0.14467 - (-0.14467) = 0.28934 м (~289 мм) ✅
```

**Проблема:** Текущий URDF путает оси! Рокеры вдоль Y, но wheelbase должен быть вдоль направления движения.

### 3.4. Высота колес

```
Fusion 360: Z = 0.028767 м (~29 мм) - высота оси над ground
Текущий:    Z = -0.01575 м (через рокер) - НИЖЕ ground! ❌
```

**Критично:** Текущие колеса находятся НИЖЕ земли!

## 4. СИСТЕМНЫЙ АНАЛИЗ

### 4.1. Система координат

#### Fusion 360
- **Z-up:** Вертикаль вверх (стандарт CAD)
- **X-forward:** Ось вращения колес вдоль X
- **Y-left:** Wheelbase вдоль Y

#### Текущий URDF (предполагаемый)
- **Z-up:** Вертикаль вверх (стандарт ROS)
- **X-forward:** Вперёд (движение)
- **Y-left:** Влево
- **Ось вращения колес:** Y-ось ❌ (должна быть X для дифференциального привода!)

**Проблема:** Возможно, текущий URDF использует другую ориентацию робота!

### 4.2. Дифференциальный привод

Для правильного дифференциального привода:
```
Левые колеса:  axis="1 0 0"  (вращение вокруг +X)
Правые колеса: axis="-1 0 0" (вращение вокруг -X)
```

Fusion 360: ✅ Правильно  
Текущий URDF: ❌ Использует Y-ось

## 6. КРИТИЧЕСКИЕ ВОПРОСЫ

### 6.1. Рокеры (подвеска)

**Fusion 360 НЕ моделирует рокеры!**

Возможные причины:
1. ❌ В реальном роботе НЕТ подвески с рокерами
2. ⚠️ Экспорт из Fusion 360 упростил модель (не экспортировал подвеску)
3. ⚠️ Подвеска есть, но моделируется иначе

**Требуется уточнение от пользователя!**

### 6.2. Ориентация робота

**Текущий URDF vs Fusion 360 используют разную ориентацию?**

Признаки:
- Fusion: Датчики высоко (Z≈0.46-0.48 м)
- Текущий: Датчики низко (Z≈0.16-0.20 м)
- Разница: ~30 см по высоте

**Возможно:**
- Fusion 360: base_link на уровне земли
- Текущий URDF: base_link поднят на 30 см (на уровне центра робота)

### 6.3. Wheelbase vs Track

**Путаница в терминологии:**
- Документация HARDWARE.md: Wheelbase=390мм, Track=289мм
- Fusion 360 URDF: X≈390мм, Y≈289мм
- Текущий URDF: Rocker length=289мм

**Нужно уточнить:**
- Что такое "wheelbase" в контексте этого робота?
- Вдоль какой оси робот движется вперед?
