## 🎯 Ключевые улучшения

### Производительность ⚡

**Скорость генерации (Raspberry Pi 5, прогноз):**
- v4: ~25-30 сек аудио/сек
- v5: ~40-50 сек аудио/сек
- **Ускорение: 1.6-2.0x** ✨

**CPU usage:**
- Снижение на 30-40% при той же скорости генерации

**Latency:**
- Снижение на 30-50% для коротких фраз

### Качество звучания 🎵

**Новые возможности:**
- ✨ Автоматическая расстановка ударений в омографах
  - замОк (дверной) vs зАмок (здание)
  - готОв (прилагательное) vs гОтов (племя)
  - мукА (продукт) vs мУка (страдание)

- ✨ Улучшенная стабильность генерации
- ✨ Более естественная интонация
- ✨ Меньше артефактов на длинных фразах

### Новые голоса 🎤

**Добавлен:**
- **eugene** - новый мужской голос

**Всего голосов в v5:**
- aidar (нейтральный М)
- baya (спокойный М) - по умолчанию
- kseniya (нейтральный Ж)
- xenia (энергичный Ж)
- eugene (новый М) ✨

### API улучшения 🔧

**Новые флаги:**
```python
audio = model.apply_tts(
    text="Текст",
    speaker="baya",
    sample_rate=48000,
    # Новые флаги v5:
    put_accent=True,         # Ударения в словах
    put_yo=True,             # Автоматическая ё
    put_stress_homo=True,    # Ударения в омографах ⭐
    put_yo_homo=True         # Ударения в омографах с ё
)
```

**Совместимость:**
- ✅ 100% обратно совместимый API
- ✅ Новые флаги опциональные
- ✅ Все старые параметры работают
