## 2. Проверка гипотезы: Координаты датчиков в системе координат меша

### Гипотеза
Возможно, старые позиции датчиков были заданы в системе координат **визуального меша body_case.stl**, а не base_link?

### Проверка

Если применить обратное преобразование к старым позициям:
1. Поворот на +90° вокруг Z (обратный к -90°)
2. Добавить offset меша

**Математика:**
```python
# Поворот +90° вокруг Z:
X_rotated = -Y_old
Y_rotated = X_old
Z_rotated = Z_old

# Добавить offset:
X_final = X_rotated + 0
Y_final = Y_rotated + (-0.18)
Z_final = Z_rotated + (-0.02)
```

| OAK-D | (0.25, 0, 0.167) | (0, 0.07, 0.147) | (-0.0002, 0.116, 0.4595) | ❌ НЕТ |
| Ceiling | (0.065, 0.171, 0.462) | (-0.171, -0.115, 0.442) | (0.065, 0.171, 0.462) | ❌ НЕТ |

**Вывод:** ❌ **Гипотеза НЕ подтверждена** - простое преобразование координат меша не объясняет расхождения.

## 3. Анализ паттернов в изменениях

### Абсолютные изменения

| Датчик | ΔX (мм) | ΔY (мм) | ΔZ (мм) |
|--------|---------|---------|---------|
| **LiDAR** | **-250.33** | +170.81 | **+276.50** |
| **OAK-D** | **-250.24** | +115.77 | **+292.50** |
| **Разница** | **0.09** | 55.03 | **16.00** |

**Наблюдения:**
- ✅ **ΔX почти одинаковые** (~-250 мм) - разница всего 0.09 мм!
- ✅ **ΔZ близкие** (+277 и +293 мм) - разница 16 мм
- ⚠️ **ΔY разные** (+171 и +116 мм) - разница 55 мм

**Интерпретация:**
Сдвиг по X и Z **примерно одинаковый** для обоих датчиков, что указывает на **возможный общий сдвиг системы координат**. Но разница по Y показывает, что датчики находятся в **разных местах** относительно друг друга.

### Относительные позиции датчиков

#### В старом URDF (LiDAR относительно OAK-D)
```
ΔX = 0.000 м (оба на X = 0.25)
ΔY = 0.000 м (оба на Y = 0)
ΔZ = 0.033 м = 33 мм (LiDAR выше на 33 мм)
```

**Вывод:** В старом URDF датчики **на одной вертикальной линии** (X=0.25, Y=0)

#### В Fusion 360 (LiDAR относительно OAK-D)
```
ΔX = -0.000093 м ≈ 0 мм (оба практически на X ≈ 0)
ΔY = 0.055 м = 55 мм (LiDAR смещен на 55 мм по Y)
ΔZ = 0.017 м = 17 мм (LiDAR выше на 17 мм)
```

**Вывод:** В Fusion 360 датчики **НЕ на одной линии** - разнесены по Y на 55 мм!

## 4. Финальные выводы

### ❌ Преобразования координат НЕ было

**Доказательства:**

1. **Относительные позиции изменились**
   - Старый URDF: LiDAR и OAK-D на одной вертикальной линии (ΔY = 0)
   - Fusion 360: Датчики разнесены по Y на 55 мм
   - **Вывод:** Это не может быть результатом простой трансформации всей системы координат!

2. **Ceiling camera уже была правильной**
   - Ceiling camera была исправлена в октябре 2025 (коммит 361942e)
   - Её позиция почти совпадает с Fusion 360
   - **Вывод:** Если бы было общее преобразование, ceiling camera тоже была бы неправильной

3. **Разные изменения по Y**
   - LiDAR: ΔY = +171 мм
   - OAK-D: ΔY = +116 мм
   - Разница: 55 мм
   - **Вывод:** Датчики перемещались **независимо**, не как единая система

### ✅ Что на самом деле произошло

**Старые позиции (август 2025):**
```xml
<!-- Предполагаемые позиции "на глаз" -->
<xacro:lidar ... origin_xyz="0.25 0 0.2"/>      <!-- "Впереди, по центру, низко" -->
<xacro:oak_d_camera ... origin_xyz="0.25 0 0.167"/>  <!-- "Впереди, по центру, чуть ниже" -->
```

**Логика старых позиций:**
- "Датчики должны быть **впереди** робота" → X = 0.25 м
- "Датчики должны быть **по центру**" → Y = 0
- "LiDAR чуть **выше** камеры" → Z_lidar = 0.2, Z_camera = 0.167

**Реальные позиции (Fusion 360):**
```xml
<!-- Точные позиции из CAD модели -->
<origin xyz="-0.000331 0.170806 0.4765"/>  <!-- LiDAR: центр, сбоку, высоко -->
<origin xyz="-0.000238 0.115772 0.4595"/>  <!-- OAK-D: центр, сбоку, высоко -->
```

**Реальность:**
- Датчики **не впереди**, а практически **по центру** (X ≈ 0)
- Датчики **не по центру по Y**, а **сбоку** (Y = 0.17 и 0.12)
- Датчики **намного выше** (~0.46 м vs ~0.17-0.20 м)

### 🎯 Почему старые позиции были неправильными

1. **Визуальная оценка vs реальность**
   - Кто-то посмотрел на робота и решил: "датчики впереди" → X = 0.25
   - На самом деле: датчики практически по центру корпуса → X ≈ 0

2. **Забыли про высоту конструкции**
   - Предположили: "датчики не очень высоко" → Z = 0.2
   - На самом деле: датчики на высоте почти **0.5 метра** от base_link!

3. **Не учли боковое размещение**
   - Предположили: "датчики по центру" → Y = 0
   - На самом деле: датчики смещены на **10-17 см** от центральной оси
