## 🔍 Что такое Grok API Voice Mode?

### Официальная информация (x.ai/api)

**Grok** — это LLM модель от xAI (компания Илона Маска), запущенная в феврале 2025.

### Доступные модели (2025)

- **grok-4** — последняя версия, продвинутые рассуждения
- **grok-4-fast-reasoning** — для аналитических задач
- **grok-3.5** — предыдущая версия (A/B тестирование voice mode)
- **grok-realtime** — для real-time приложений

### Voice Mode возможности

По данным официальной документации и тестирований (ноябрь 2025):

#### ✅ Что ПОДДЕРЖИВАЕТСЯ:

1. **Streaming текстовых ответов** (Server-Sent Events)
   ```python
   # Пример из официальной документации
   client = Client(api_key=os.getenv('XAI_API_KEY'))
   chat = client.chat.create(model="grok-4")
   chat.append(system("You are Grok, a chatbot."))
   chat.append(user("Tell me a joke."))
   for response, chunk in chat.stream():
       print(chunk.content, end="", flush=True)
   ```

2. **Voice Mode в веб/мобильном интерфейсе**
   - Пользователь отправляет голосовые сообщения
   - Получает синтезированные аудио ответы
   - Работает на iOS, постепенный rollout на Android

3. **Огромное контекстное окно**
   - До 1 миллиона токенов
   - Идеально для сложных диалогов с историей

4. **Function calling** (вызов функций)
   - Интеграция с роботом (навигация, сенсоры)
   - Structured outputs

5. **Real-time search**
   - Доступ к актуальной информации

#### ❌ Что НЕ ПОДДЕРЖИВАЕТСЯ (критично!):

1. **НЕТ прямого API для audio input/output**
   - API работает только с текстом (chat/completions)
   - Voice mode доступен только в веб/мобильном UI
   - Нет WebRTC endpoints для аудио стриминга

2. **НЕТ встроенного STT**
   - Grok API не принимает аудио на вход
   - Требуется отдельный STT сервис

3. **НЕТ встроенного TTS**
   - Grok API не генерирует аудио напрямую
   - Требуется отдельный TTS сервис

**Важный вывод:** Voice mode в Grok — это **UI feature** веб/мобильного приложения, а не API feature!

## 🔧 Техническая реализуемость

### Сценарий: Замена DeepSeek на Grok в dialogue_node.py

#### Шаг 1: Установка SDK

```bash
# Grok использует OpenAI-совместимый API
pip install openai
```

#### Шаг 2: Изменение кода

```python
# БЫЛО (DeepSeek):
from openai import OpenAI

client = OpenAI(
    api_key=os.getenv("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com"
)

# СТАЛО (Grok):
from openai import OpenAI

client = OpenAI(
    api_key=os.getenv("XAI_API_KEY"),
    base_url="https://api.x.ai/v1"
)

# Модель
model = "grok-4"  # вместо "deepseek-chat"
```

#### Шаг 3: Конфигурация

```yaml
# config/voice_assistant.yaml
dialogue_node:
  ros__parameters:
    llm_provider: "grok"  # вместо "deepseek"
    api_key: "${XAI_API_KEY}"
    base_url: "https://api.x.ai/v1"
    model: "grok-4"
    temperature: 0.7
    max_tokens: 500
```

#### Шаг 4: Переменные окружения

```bash
# docker/vision/.env.secrets
export XAI_API_KEY="xai-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

**Сложность реализации:** ⭐ Низкая (API совместимо с OpenAI)

**Время реализации:** ~2-4 часа (включая тестирование)
