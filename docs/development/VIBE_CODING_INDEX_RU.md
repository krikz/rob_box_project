# Рефакторинг для Vibe Coding - Индекс документации

## 📖 Что это?

Комплексный план рефакторинга трех AI-пакетов для улучшения разработки с помощью AI (vibe coding).

## ❓ Проблема

Код AI-агента разросся до 2000+ строк в одном файле:
- ❌ LLM галлюцинирует (не влезает в контекст)
- ❌ Тяжело тестировать
- ❌ Сложно поддерживать
- ❌ Медленная разработка

## ✅ Решение

Разбить на модули по <300 строк с четким разделением:
- ✅ Каждый модуль влезает в контекст LLM
- ✅ Легко тестировать
- ✅ Понятная структура
- ✅ Быстрая разработка (2-3x)

## 🎯 Основные принципы

1. **<300 LOC**: Каждый файл должен быть меньше 300 строк
2. **Одна ответственность**: Один модуль = одна задача
3. **Тестируемость**: Core без зависимостей от ROS/API
4. **Слои**: core → adapters → nodes
5. **Документация**: README у каждого модуля
6. **Постепенность**: Не ломаем существующий код
