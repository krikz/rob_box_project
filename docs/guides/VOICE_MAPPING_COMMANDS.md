# Голосовые команды управления картами RTABMap

## 🎤 Доступные команды

### 1. Начать новое исследование
```
Пользователь: "Роббокс, начни новое исследование"
Робот: "Начать новое исследование? Текущая сессия будет завершена, 
        старая карта сохранится в базе данных."
Пользователь: "Да"
Робот: "Начинаю новое исследование. Создана новая сессия картографии."
```

**Что происходит:**
- Вызывается `/rtabmap/reset_memory`
- Создаётся новая сессия в rtabmap.db
- Старая карта остаётся в БД (multi-session)

**Варианты команды:**
- "исследуй территорию"
- "создай новую карту"
- "начни картографию"

---

### 2. Продолжить исследование
```
Пользователь: "Роббокс, продолжи исследование"
Робот: "Продолжаю исследование территории. Добавляю новые области к карте."
```

**Что происходит:**
- Вызывается `/rtabmap/set_mode_mapping`
- Переключается в SLAM режим
- Продолжает дополнять текущую карту

**Варианты команды:**
- "продолжить картографию"
- "добавь к карте"

---

### 3. Закончить исследование
```
Пользователь: "Роббокс, закончи исследование"
Робот: "Заканчиваю исследование. Переключаюсь в режим навигации по готовой карте."
```

**Что происходит:**
- Вызывается `/rtabmap/set_mode_localization`
- Переключается в режим локализации
- Карта становится read-only

**Варианты команды:**
- "завершить картографию"
- "перейди в навигацию"
- "режим локализации"

---

### 4. ⚠️ Удалить все карты (НОВОЕ!)
```
Пользователь: "Роббокс, удали все карты"
Робот: "ВНИМАНИЕ! Удалить ВСЕ карты из базы данных? 
        Это действие нельзя отменить. Будет создана резервная копия."
Пользователь: "Да"
Робот: "Все карты удалены. БД удалена (XX МБ). 
        RTABMap создаст новую при запуске."
```

**Что происходит:**
1. Вызывается `/rtabmap_manager/delete_all_data`
2. Создаётся backup: `/maps/deleted_backups/rtabmap_deleted_YYYYMMDD_HHMMSS.db`
3. Удаляется `/maps/rtabmap.db`
4. RTABMap автоматически создаст новую пустую БД при следующем использовании

**Варианты команды:**
- "удалить все карты"
- "очисти все карты"
- "стереть все карты"
- "удали базу данных"
- "очистить память"
- "сбрось всю память"

## 🔧 Технические детали

### RTABMap Manager Node

**Пакет:** `rob_box_rtabmap_manager`

**Нода:** `rtabmap_manager_node`

**Запускается:** В контейнере rtabmap (Main Pi)

**Сервисы:**
- `/rtabmap_manager/delete_all_data` (std_srvs/Trigger)
  - Возвращает: `success` (bool), `message` (string)

**Параметры:**
```yaml
db_path: /maps/rtabmap.db          # Путь к БД
backup_dir: /maps/deleted_backups  # Директория для backup
auto_backup: true                  # Автоматический backup перед удалением
```

## 📊 Сравнение операций

| Команда | БД удаляется? | Старые карты? | Backup |
|---------|---------------|---------------|---------|
| **Начать новое исследование** | ❌ Нет | ✅ Сохраняются как неактивные сессии | Не нужен |
| **Удалить все карты** | ✅ Да | ❌ Удаляются полностью | ✅ Автоматический |

## 🗂️ Файловая структура /maps/

```
/maps/

    ├── rtabmap_deleted_20251117_140530.db
    ├── rtabmap_deleted_20251117_150215.db
    └── ...
```

## 🚨 Важные примечания

### ⚠️ Когда использовать "удали все карты":
- Робот работает в новой локации
- БД слишком большая (занимает много места)
- Карты повреждены или содержат ошибки
- Нужно полностью очистить память для тестирования

### ✅ Когда использовать "начни новое исследование":
- Обычная ситуация - исследование новой области
- Хотите сохранить старые карты в БД
- БД не слишком большая (< 1ГБ)

### 💡 Ручное управление backup:

Восстановить из backup:
```bash
# SSH на Main Pi
ssh ros2@10.1.1.20
cd ~/rob_box_project/docker/main/maps

# Остановить rtabmap
docker-compose stop rtabmap

# Восстановить БД
cp deleted_backups/rtabmap_deleted_20251117_140530.db rtabmap.db

# Запустить rtabmap
docker-compose up -d rtabmap
```

Проверить размер БД:
```bash
du -h /path/to/maps/rtabmap.db
# Если > 500МБ - рекомендуется очистка старых сессий
```

## 🧪 Тестирование команды

### Вручную через ROS:
```bash
# Проверить что сервис доступен
ros2 service list | grep rtabmap_manager

# Вызвать сервис напрямую
ros2 service call /rtabmap_manager/delete_all_data std_srvs/srv/Trigger
```

### Проверить логи:
```bash
# Main Pi - логи rtabmap_manager
docker logs rtabmap -f | grep rtabmap_manager

# Vision Pi - логи dialogue_node
docker logs voice-assistant -f | grep delete_all
```
