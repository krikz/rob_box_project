### 1.2 Что умеет и чего не умеет наш синтез (на 13.10)

Аранжировщик v2 (ADR-0149/0153/0157): пьеса по названию (партитура PDMX / RTTTL-хук), DJ-сет в стилях `club, rave, synthwave, chiptune, breaks, dnb` (+ `lofi` — PR #3586 ждёт Шифу, судья 3/10; `rock` — забракован Шифу, #3597; `jazz` — есть в `STYLES`), мгновенно (≤ 3 с), бесплатно, детерминированно, со стыками на двух деках. Не умеет: **голос и текст** (петь), **живые инструменты** (балалайка, гитара, оркестр — паков нет, ADR-0157 §2.4, исследование #3587), **жанры, где нужен «настоящий» звук** (рок/гранж — забракован, металл, блюз, шансон, акустика).

Генерация (Suno) закрывает ровно эти дыры, но: секунды-десятки секунд ожидания, деньги, сеть, недетерминированность, нельзя «сыграть Токкату Баха» по нотам (генератор не воспроизводит конкретную мелодию по названию). Поэтому путь выбирает **код по структуре запроса**, а не LLM и не «всегда генерация».

## 2. Решение

Пять принципов — продолжение ADR-0148/0157.

### 2.1 Генератор — провайдер за интерфейсом, без тихой деградации

```python
class MusicGenProvider(Protocol):
    name: str                                         # "kie_suno"
    def submit(self, job: GenJob) -> GenTicket        # GenUnavailable(reason) — сразу, без звука
    def poll(self, ticket: GenTicket) -> GenStatus    # stage ∈ {queued, text, first, complete, failed}; tracks[] частичные
    def balance(self) -> Credits | None               # GET /api/v1/chat/credit; None — неизвестно

@dataclass(frozen=True)
class GenJob:
    kind: Literal["instrumental", "song", "robot_song"]     # "cover" — после §8 В7
    style_key: str            # ключ GEN_STYLES (§3.2), теги Suno — из таблицы, не из LLM
    title: str
    duration_s: int           # 60..360, по умолчанию 150
    lyrics: str = ""          # song / robot_song
    vocal_path: str = ""      # robot_song: mp3 TTS (загружается в KIE, живёт 24 ч)
    model: str = "V6"         # ключ GEN_MODELS
```

`GenUnavailable.reason` — перечень: `no_key`, `no_credits` (KIE `code=402`), `rate_limited` (429), `provider_down` (455/5xx/таймаут сети), `rejected` (422/400 — контент, параметры), `timeout` (нет `complete` за `GEN_TIMEOUT_S` = 180 с), `budget_exhausted` (наш дневной лимит, §2.6). Каждой причине — **фраза из кода** (`media_phrases`), а дальше — правило §2.2 «что делаем без генерации». Первый и пока единственный провайдер — **Suno через KIE** (`kie_suno`); второй (Udio, MiniMax, если вернётся) встаёт за тот же интерфейс без правки вызывающих. HTTP 200 + `code` ≠ 200 — ошибка (у KIE HTTP-статус всегда 200). Callback `callBackUrl` не используем: у робота нет публичного адреса; опрос `record-info` с шагом 2 → 4 с (лимит запросов — §1.3).

### 2.2 Чойсер «генерация или синтез» — кодом по слотам запроса

Решает функция `music_source(cmd: MediaCommand, ctx) -> Route` в `rob_box_music` (чистый Python), где `Route = {source: synth|generate|hybrid, reason, job?}`. LLM путь не выбирает: она может только заполнить пустые слоты **из перечня** (как в ADR-0157 §2.1). Новые слоты грамматики (`media_command_grammar.MediaCommand`, рядом с `instrument`, `style`, `name`): `vocal` («спой», «песню», «со словами», «с текстом»), `robot_voice` («своим голосом», «сам спой», «спой ты»), `own` («свою», «сочини», «придумай»), `fresh` («новую», «другую», «ещё не играл»), `generated` (явное «сгенерируй», «нейросетью», «через суно»), `genre` — ключ `GEN_STYLES` для жанров вне наших `STYLES` («гранж», «рок», «металл», «блюз», «шансон», «оркестр», «акустика»).

Правила по порядку (первое сработавшее):

| # | Слоты запроса | Путь | Почему |
|---|---|---|---|
| 0 | `stop / volume / now_playing` | как сегодня | не музыка |
| 1 | `generated` («сгенерируй …») | **генерация** | явная просьба |
| 2 | `vocal` + `robot_voice` или `vocal` без указания голоса | **генерация: песня РОББОКСа** (§2.3) | петь синтез не умеет; голос робота — одобрен Шифу 13.10 |
| 3 | названное произведение (`PLAY_NAMED`, кандидаты по реестру ADR-0157 §3.2) | **синтез** (пьеса) | мгновенно, бесплатно, узнаваемо; генератор не играет чужую мелодию по названию |
| 4 | названное произведение + инструмент **без пака** («Бах на балалайке») | **синтез** с фразой о соседнем инструменте (ADR-0157 §2.4) — сегодня; **гибрид-кавер** — после В7 | см. §3.6 |
| 5 | сет/трек в стиле с `STYLES[s].source == "synth"` (`club, rave, synthwave, chiptune, breaks, dnb`) | **синтез** | наши сильные стили; стыки на деках; бесплатно |
| 6 | сет/трек в стиле с `source == "generate"` (сегодня `rock` — забракован, и все `GEN_STYLES` вне `STYLES`) | **генерация** | синтез слаб или нет вовсе |
| 7 | `own`/`fresh` в стиле `synth` | **синтез** с новым сидом | «сочинить своё» аранжировщик умеет; генерация — только по `generated` |
| 8 | ничего не сказано про стиль («включи музыку») | **синтез** (как сегодня) | дешевле и мгновенно |

`Style.source ∈ {synth, generate, both}` — **поле данных стиля** (ADR-0153: стиль как данные), Шифу переключает стиль на слух одной строкой; `both` значит «сет чередует» (гибрид, §2.4). Фраза о выборе пути — от кода по `Route.reason` («рок у меня своими силами пока не звучит — сгенерирую, это около полуминуты»).

**Что без генерации (нет ключа/денег/провайдер лёг/таймаут):** путь 6 и 1 для инструментала → честная фраза + **наш синтез** ближайшим стилем по таблице соседей (`club` для `rock` — значение в данных); путь 2 (песня) → честная фраза **без** подмены инструменталом («спеть сейчас не могу: <причина>») — синтез не поёт, подсовывать трек вместо песни — та самая тихая деградация. Если Шифу решит иначе — §8 В3.

### 2.3 Песня РОББОКСа — голос робота + Suno `add-instrumental`

Пайплайн, одобренный на слух 13.10 («Suno справился хорошо, надёжный мужик звучит хорошо»):

```
слоты (тема, жанр, настроение) ──► LLM: {title, lyrics} строго по JSON-схеме (правила скилла §3.4)
   ──► валидатор кода (длина ≤ 950 симв. ≈ 80 с, строки, нет пустоты, язык ru)
   ──► MiniMax TTS speech-02-hd, voice Russian_ReliableMan, emotion из таблицы жанра ──► vocal.mp3 (~2 с)
   ──► KIE file-stream-upload (живёт 24 ч) ──► add-instrumental V6: tags/negative_tags из GEN_STYLES[жанр],
       vocal_gender=m, audio_weight=0.8, lyrics ──► 2 варианта ~75 с (~46 с)
   ──► кэш (оба варианта) ──► играет вариант 0 через деку (§2.4) ──► фраза успеха от кода из результата
```

LLM пишет **только текст** (свой, не перевод и не пересказ чужой песни — правило скилла; проверить «не чужое» код не может, это честно указано в §9). Название, длительность, жанр во фразе успеха — из полей результата (`title`, `duration`), не из ответа LLM. Клон голоса через Suno Voice (validation-phrase) **не рассматривается**: это проверка владельца голоса, синтетикой мы её не проходим (решение координатора). Ожидание: LLM (не мерено) + 2 с TTS + ~46 с генерации ≈ 1 мин; пока ждём — короткая фраза кода «пишу песню, минута» и тишина (или синтез-подложка, §8 В4). TTS зависит от денег MiniMax (память «голосовой стек деградирует молча») — отказ TTS даёт `GenUnavailable(provider_down)` с фразой, а не тишину.

### 2.4 Сгенерированный звук — через деки `PlayerOwner`, а не мимо

Сегодня mp3 играет `sound_node` мимо движка (§1.1). Для сета и для «одного владельца состояния» (ADR-0149 §2.1) это недопустимо: нет блэнда, нет `started/nearly_finished/finished`, громкость своя, занятость устройства — молчаливый пропуск. Решение — **одна реализация воспроизведения музыки**: сгенерированный трек — второй вид артефакта деки.

```python
@dataclass(frozen=True)
class AudioTrack:              # рядом с Track (модель v2), в rob_box_music.model
    track_id: str; path: str; duration_s: float
    bpm_nominal: int | None    # из GEN_STYLES/запроса; бит-сетка не гарантирована
    loudness_lufs: float       # замер при сохранении в кэш (ffmpeg ebur128), выравнивание к цели мастер-шины
    source: Literal["generated"]
```

`render(AudioTrack, deck)` → программа деки, которая играет буфер SuperCollider (mp3 → wav на частоте сервера при сохранении в кэш, один раз), `PlayerOwner` шлёт те же события по клоку (длина в долях = `duration_s × bpm/60`), стоп/громкость/«что играет» — тем же путём. Стыки: сгенерированный ↔ сгенерированный и синтез ↔ сгенерированный — **кроссфейд 8 тактов** по `bpm_nominal` с LPF уходящего/HPF входящего (ADR-0149 §3.12, ADR-0157 PR-5), **без** бит-матчинга (сетка Suno не гарантирована; librosa дал 112.3 на заказанные 110 — близко, но это один стиль и 8 треков). После переезда удаляются `/voice/sound/play_file` и `sound_node.play_file_*` (§7). Ограничения, которые надо снять замером до PR-2: память буфера (180 с × 2 канала × 48 кГц × 4 Б ≈ 69 МБ; моно 16 кГц ≈ 11.5 МБ — выход робота всё равно 16 кГц ReSpeaker), время загрузки буфера на Pi, поддержка mp3 в libsndfile сервера (если нет — wav).

### 2.5 Кэш — переделанная `/data/music_library`, а не вторая библиотека

Генерация → **всегда** в кэш (оба варианта), KIE удаляет файлы через 14 дней. Библиотека — та же (`generated_music_library.py` переезжает в `engine/gen/library.py`, одна схема; `migrations/007` удаляется), схема дополняется:

| Поле | Зачем |
|---|---|
| `request_key` | `sha256(json{kind, style_key, theme_norm, lyrics_sha, voice, provider, model, duration_bucket})`; `theme_norm` — тема после выделения слотов, нижний регистр, леммы (как `theme_grounding`) |
| `pool_key` | `(kind, style_key, instrumental)` — «любой трек этого стиля» для сетов |
| `provider`, `model`, `task_id`, `variant` (0/1), `credits` | учёт и повторяемость |
| `bpm_nominal`, `key_est`, `loudness_lufs` | стыки и выравнивание (§2.4); `key_est` — librosa офлайн при сохранении (опционально, §8 В6) |
| `last_played_at`, `play_count`, `rating` (−1/0/+1) | свежесть и вкус (ADR-0146) |

Когда отдавать из кэша, а когда генерить — **кодом**:

| Запрос | Кэш | Генерация |
|---|---|---|
| совпал `request_key`, есть вариант, не игранный за последние `H` часов (`GEN_FRESH_HOURS`, предложение 24) и `rating ≥ 0` | **да** — мгновенно, бесплатно; фраза «эту я уже сочинял — ставлю» | нет |
| совпал `request_key`, но все варианты свежо играны / `rating < 0` | нет | да |
| слоты `fresh` («новую»), `generated` | нет | **всегда** |
| сет: пул `pool_key` | берём из пула кандидатов (`Chooser` ADR-0157: признаки — тема-совпадение, давность, рейтинг, тональность к соседу) столько, сколько их не играно за `H` | дефицит — генерим (§2.6 бюджет) |
| песня по названию («спой ту про батарейку») | поиск по `title/lyrics` | нет |

Второй вариант каждой задачи — «в запас»: в тот же сет — **не соседом** (§1.4); в следующий раз по тому же `request_key` играет он, а не первый (повтор исчезает по построению). История сыгранного — общая с сетами синтеза (`music_history`, ADR-0146; `HistoryKey("gen_v1")`). Диск: ≈ 2.7 МБ/120 с, ≈ 4.2 МБ/180 с mp3 → 1 ГБ ≈ 240–380 треков; квота `GEN_LIBRARY_MAX_MB` (предложение 2048) с вытеснением «давно не играли, `rating ≤ 0`, есть второй вариант той же задачи». Свободное место на `/data` Pi — замерить в PR-1 (§9).

### 2.6 Деньги — счётчик и бюджет кодом

Таблица `gen_ledger(task_id, ts, credits, kind, request_key)` в той же `index.db`; перед `submit` код проверяет **дневной бюджет** `GEN_DAILY_CREDITS` (предложение 120 = $0.60/день по цене брифа) и **бюджет сета** `GEN_SET_CREDITS` (предложение 60 = 5 задач); после `complete` записывает `creditsConsumed` из ответа (не оценку). Раз в час и при `402` — `balance()`; баланс < стоимости задачи → `GenUnavailable(no_credits)`. Фразы — от кода: «на генерацию на сегодня бюджет вышел — дальше играю своё» (сет) / «спеть сейчас не могу — кончились кредиты генерации» (песня). Баланс и траты дня — в снимке `/voice/music/state.gen` для «сколько осталось» без LLM.

**На 13.10 баланс KIE = 8 кредитов — меньше одной задачи (12).** Без пополнения любая генерация упрётся в `no_credits`.

### 2.7 Сет из сгенерированных треков

Да, сет возможен (§1.3: генерация в 3–6 раз быстрее длины трека):

- **Опережение на 1**: на `started(N)` заказывается `N+1` (из кэша — мгновенно; иначе `submit`). Трек 150 с, генерация 20–52 с → запас ≥ 100 с. Не готов к `nearly_finished(N)` → продлить N (повтор формы невозможен у mp3 → кроссфейд на второй вариант той же задачи, §1.4 — он той же тональности/темпа) или мост синтезом в том же темпе.
- **Первый трек**: из кэша, если есть (мгновенно); иначе ожидание ≈ 25–50 с (V6_MINI 20–37 с по 3 замерам) с фразой кода «запускаю, полминуты». Ранний старт со `stream_audio_url` (~21 с у V6 против ~38 с первого полного mp3) — **не доказан** (§0): если стрим отдаёт звук до `success` быстрее реального времени, первый трек стартует на ~10–15 с раньше. Замер — первая задача PR-5, ~12 кредитов.
- **Темп**: один `bpm` на сет кладётся в теги Suno («… 124 bpm …»); бит-матчинг не обещаем, стык — кроссфейд (§2.4).
- **Цена сета из 10 треков по 150 с**: 10 задач × 12 = 120 кредитов ≈ **$0.60** (20 вариантов, 10 уходят в кэш) — или 5 задач ≈ $0.30, если вторые варианты ставить через трек (A₁ B₁ A₂ B₂ …) — §8 В5. Со второго такого же сета — частично из кэша.
- **Модель**: V6_MINI для сетов (быстрее, та же цена), V6 для песни РОББОКСа (`add-instrumental` мерен только на V6) — §8 В2.

### 3.2 `GEN_STYLES` (первый состав — данные, правит Шифу)

| Ключ | Слова в грамматике | Теги Suno (EN) | Сосед синтеза при отказе |
|---|---|---|---|
| `grunge` | гранж, гранжевый | 90s grunge rock, loud-quiet-loud, distorted power chords, heavy drums, raw garage | `club` |
| `rock` | рок, роковый | (из `_ROCK_STYLE` словами) | `club` |
| `metal` | металл, метал | heavy metal, … | `rave` |
| `blues`, `chanson`, `orchestral`, `acoustic`, `jazz_vocal` | … | … | по таблице |
| `synthwave`, `club`, … (`both`) | как в `STYLES` | синонимичные теги — для гибрида | — |

### 3.3 Тул `generate_music` (возвращается узким)

`generate_music(kind: enum[instrumental, song, robot_song], style: enum[GEN_STYLES], theme: str ≤ 60, fresh: bool)`; скрытые аргументы хода `heard_text`; `llm_visible=True`, асинхронный (возвращает `job_id` сразу, звук — по событию `started`). Тул не принимает `lyrics` и теги Suno от LLM: текст песни LLM даёт в **отдельном** структурном вызове внутри `song.py` по схеме, теги — из таблицы. Списки «музыкальных тулов» (§1.1, 4 места) сводятся к одной константе в `rob_box_core.tool_catalog` (флаг `starts_music` уже есть у `MCPTool`).

### 3.4 Правила текста песни (скилл `song.txt`, коротко)

Свой текст на русском; 2 куплета + припев ×2, 8–12 слогов в строке; тема из слота; от первого лица робота; без цитат чужих песен и без перевода чужих; ≤ 950 символов; ответ — JSON `{title ≤ 40, lyrics}`. Код отвергает невалидное и повторяет **один** раз; второй отказ → фраза «текст не сложился» (без синтетических ретраев сверх одного — ADR-0148).

### 3.5 Ошибки KIE → причины

| KIE `code` | Причина | Повтор |
|---|---|---|
| 401 | `no_key` | нет |
| 402 | `no_credits` | нет |
| 429 | `rate_limited` | 1 раз через 10 с |
| 455, 500, 5xx, сеть | `provider_down` | нет; circuit breaker 10 мин |
| 400, 422, `state=fail` | `rejected` (`failMsg` — в лог) | нет |
| нет `complete` за 180 с | `timeout` | нет (задача может доиграть — результат всё равно в кэш, кредиты учтены) |

### 3.6 Гибрид (после решений §8)

- **Мост синтезом**: первый трек сгенерированного сета не готов → синтез в том же темпе и ближайшем стиле играет, пока генерация не завершится, затем кроссфейд.
- **Сет `both`**: стиль, где сильны оба пути (synthwave), — чередование синтез/генерация через трек; стык синтез ↔ mp3 — кроссфейд.
- **Кавер нашей аранжировки** (`upload-and-cover-audio`): наш NRT-рендер «Токкаты» → Suno «on balalaika, russian folk» — мелодия наша (общественное достояние), тембр живой. Закрывает «Бах на балалайке» без пака. Не мерено; один опыт ≈ 12 кредитов — §8 В7.
