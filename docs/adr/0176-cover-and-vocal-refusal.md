# ADR-0176: Кавер и вокал в одной реплике — честный отказ, не склейка

| Поле | Значение |
|---|---|
| Статус | Принято (решение товарища Шифу 30.10, вариант А; карточка #4014, after-epic) |
| Дата | 2026-11-21 |
| Issue | [#4014](https://github.com/krikz/rob_box_project/issues/4014) |
| Связано | ADR-0148 (код решает, фразу строит код), ADR-0158 §2.9 (кавер без вокала), ADR-0158 §3.4 (песня робота — свой текст), #4015 (`named_song`) |

## Проблема

Одна реплика просит и кавер названной пьесы, и вокал: «сыграй X и спой», «сгенерируй X и спой».

Кавер (ADR-0158 §2.9, `upload-and-cover-audio`) вокала не несёт. Песня робота (`engine.gen.song`) поётся своим текстом, не чужим (ADR-0158 §3.4). Пути «кавер + вокал» нет. Живой прогон 24.10: такая реплика ушла в синтез без вокала и без честной фразы, чего робот не умеет.

«Спой X» — другая карточка (#4015, причина `named_song`: «чужие песни по названию я не пою»). Её причина здесь не переиспользуется: человек просил и сыграть, и спеть, а не только спеть чужое.

## Решение

Решает код, не промпт (ADR-0148).

1. Факт реплики — `source.cover_and_vocal_asked`: в одной реплике есть глагол «сыграй» (`knowledge.SING_PLAY_VERBS`) или «сгенерируй» (`SING_CREATE_VERBS`) и глагол «спой» (`SING_VERBS`). Слова берутся из таблиц, которые уже читает путь пения. Новой регулярки нет (мораторий #3132).
2. `source_ask` кладёт факт в `SourceAsk.cover_and_vocal`.
3. Маршрут (`source_candidates`): названная пьеса (`CoverWork.named`) и этот факт — один кандидат `decline:cover_and_vocal`. Кавер-кандидата нет. Заказа песни нет. Причина не `named_song`.
4. Заказ (`RequestMusicTool.order`) отказывает до маршрута, если факт есть и пьеса названа: ни кавер, ни песня робота не стартуют.
5. Фразу строит `decline_text` из `REASON_WORDS["cover_and_vocal"]`: кавер — без вокала, песня робота — свой текст; вместе это не одно.

«Сыграй X» без «спой» остаётся кавером. «Спой X» без «сыграй»/«сгенерируй» остаётся `named_song`. Пьесу подобрал код, а не назвал человек — этот отказ не применяется.

## Почему не другое

- Склеить кавер и вокал одним заказом — такого пути у KIE в этом репо нет. Делать его сейчас — не решение 30.10 (вариант А, не Б).
- Ответить фразой `named_song` — неправда: человека просили не только спеть чужое, а ещё и сыграть.
- Новая регулярка в `media_command_grammar.py` — запрещена мораторием #3132 без разрешения Шифу. Грамматика по-прежнему может проглотить «и спой» в название; факт читается из таблиц глаголов, не из грамматики.
- Промпт «не обещай кавер с вокалом» — модель может соврать или промолчать (ADR-0148). Отказ обязателен и без облака.

## Цена

- «Сыграй X и спой» не начинает ни кавер, ни песню. Человек должен сказать одно из двух отдельно. Это и есть отказ, не деградация в синтез.
- «Сгенерируй рок и спой» без названной пьесы этим отказом не закрывается: кавера пьесы там нет, путь песни робота остаётся. Карточка — про названную пьесу.
- Живой звук и поведение на роботе этим ADR не проверены.
