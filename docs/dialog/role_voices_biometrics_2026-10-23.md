# Голоса ролей марафона по биометрии (#3931, эпик #3683)

> **Каст из этого документа заменён 26.10 (#3992): `role_voices_biometrics_2026-10-26.md`.** Четыре низких
> мужских Russian_* ниже для робота — один человек (0.9); новый каст подобран по эмбеддингам живого канала.
> Замер 23.10 (254 проигрыша) остаётся базой: новые матрицы считаются вместе с его записями.

Решение товарища Шифу 23.10: голоса тестовых ролей подбирать замером, а не на слух; роботу они должны
быть (1) слышны, включая вейк-слово «Робот», и (2) различимы между собой. Первая редакция (утро 23.10, #3969)
мерила файлы синтеза, а в марафоне 16:15 UTC на живом канале 34 из 92 фраз потеряли «Робот». Эта редакция
заменяет её: все цифры ниже сняты на ЖИВОМ канале.

## Коротко (честный итог)

- **Критерий Шифу не достигнут.** Вейк ≥ 19 из 20: лучшие голоса дают 85–92 % (16–19 из 18–22), ни один не
  дотянул. Различимость «чужие ≤ 0.62» достижима только между низким мужским и высоким голосом, а не для четырёх ролей.
- **Что выяснилось.** Питч и темп из первой редакции (+5/1.2, −5/0.85) *ломали вейк* (Борис 3 из 8) и
  *не разводили* голоса: на живом канале эмбеддинг робота определяется регистром (низкий мужской / высокий),
  а не питчем. Все низкие мужские голоса MiniMax (ReliableMan, HandsomeChildhoodFriend, AttractiveGuy) для робота —
  один человек (cos 0.8–0.9 при пороге 0.72). Это потолок MiniMax: русских голосов всего 8.
- **Что сделано в таблице.** Просодия снята (0 / 1.0), оставлен только питч +2 у Бориса. Борис теперь отличим от
  Саши (макс 0.71, медиана 0.63). Саша/Гриша/Валера — по-прежнему один тембр для робота; сценарии, где робот
  должен их *различать*, на MiniMax не пройдут (см. «Что дальше»).

## Как мерили

Стенд: колонка katana (10.1.1.249) → воздух → ReSpeaker на Sound Pi → Yandex STT + resemblyzer. Проигрывание как у
харнесса: wav MiniMax `speech-02-hd` → `highpass=f=100,volume=3.0,alimiter=limit=0.98,adelay=1500|all=1`,
16 кГц mono → `pactl set-sink-volume 100%` → `paplay`. Ждать тишины в мастерской не ждали (фоновые разговоры есть).

- **Вейк:** фразы «Робот, …» (20 разных, 3–15 слов, `phrases` в evidence). Проигрыш привязан к записи
  `/audio/speech_audio` (одноразовый контейнер `docker run --network host`, образ voice-assistant) по времени и длительности;
  её `ПРИНЯТО (respeaker)` без `[backlog] accumulated reason=no_wake` — попадание (HIT), с `no_wake` — MISS,
  без `ПРИНЯТО` — NO_STT. Построчно: `evidence/role-voices-live-2026-10-23/wake_per_play.txt`.
- **Различимость:** те же записи, которые получил `speaker_id_node` (`/audio/speech_audio`), эмбеддинги тем же кодом,
  что `SpeakerDatabase.embed_audio_ex` (`preprocess_wav` + `VoiceEncoder.embed_utterance`, L2). «Профиль» = фразы 1–5
  голоса, «тест» = фразы 6+, `cos` = максимум по профилю (как `identify`). «К чужим» — максимум и медиана по ВСЕМ парам
  записей A×B (строже, чем профиль/тест). Порог опознания 0.72 не трогали.
- **Независимые синтезы (по просьбе Шифу):** финалисты синтезированы несколько раз независимо (ключ кэша обойдён — свой
  скрипт без кэша): фразы 1–8 дважды (`…r2`), 9–16 один раз. MiniMax произносит одну фразу каждый раз чуть по-разному.
- **Бюджет MiniMax: потрачено 244 синтеза из 300** (ошибок 0, лишних ретраев нет). Silero — локально на katana, бесплатно.

## Что отвергнуто и почему

- **Питч/темп как средство разведения** — не разводит (ReliableMan +3/1.12 к ReliableMan 0: 0.88; Bad-tempered 0 → +5/1.2: 0.94;
  сдвиг тембра ±20 % ffmpeg `asetrate` к себе же: 0.84–0.91) и ломает вейк (+5/1.2: 3/8, +4: 12/20, +2: 16/18). Согласуется с
  выводом 22.09 (vosk WER) и ADR-0134.
- **Межпровайдерные пары** (по идее Шифу: MiniMax + Silero): Silero v4 `eugene/aidar/kseniya/xenia/baya`, вейк 4/4 у каждого
  (по 4 фразы). Косинусы — по тому же принципу регистра: мужской Silero против низкого MiniMax 0.82–0.86
  (eugene×Саша 0.85), женский Silero против высокого MiniMax 0.75–0.89; низкая пара «мужской против женского»
  (eugene×PessimisticGirl 0.61, eugene×baya 0.62) та же, что и внутри MiniMax. Лучшая тройка без legacy-голосов — 0.80.
  Лучшая четвёрка вообще (AttractiveGuy, PessimisticGirl, audiobook_male_2, cute_boy) — 0.745 (выше порога опознания), лучшая тройка 0.67
  (cute_boy, eugene, baya); это legacy китайские или детские голоса, для ролей людей неестественны.
  Правку харнесса (провайдер на роль в строке `map_tts_voice`) не делали: выигрыша нет, а риск расползания таблицы есть.
- **Legacy-голоса MiniMax** (`male-qn-*`, `presenter_*`, `audiobook_*`, `clever_boy`, `cute_boy`, `female-*`): по 4 фразы, вейк 2/4–4/4.
  Русский STT понимает; `presenter_female` взят запасным (13 проигрышей), `cute_boy` мерили слабо (4 фразы), в таблицу не взят.
- **Yandex** не мерили: ключ на роботе отвечает `PERMISSION_DENIED` (см. 22.09).
- **Голоса, которых нет:** `get_voice` MiniMax отдаёт 332 системных голоса, русских — только 8 (все в каталоге).

## Что дальше (решения за координатором и Шифу)

1. Сценарии, где робот *обязан различить* Сашу, Гришу и Валеру (акт 3 «диаризация», 2b/2c), на MiniMax-голосах не
   пройдут: тембр один. Варианты: оставить различение только пары Саша/Борис (акты 2, 2b, 2c — он различим), а Гришу и Валеру
   проверять по тексту/адресации, а не биометрии; либо записать эталонные реплики разных живых людей.
2. Вейк даже на нейтральных голосах теряется в 8–15 % проигрышей (Yandex STT режет первое слово или шум ReSpeaker). Это потолок
   канала, а не голоса: реальная цель «19 из 20» требует работы над каналом/STT (гейн, фразовая пауза), а не подбора голоса.
3. Хвост «Робот,» → пауза → фраза не мерили; запись `[backlog]` без вейка в марафоне должна учитываться как ожидаемая доля потерь.

## Не проверено

- Вейк при варианте «Робот!» (восклицание) и паузе после вейка (`<#0.4#>`) — не успели (бюджет стенда).
- Silero и legacy-голоса — по 4 фразы (малая выборка); в итоговую таблицу не вошли.
- Произношение на слух (Шифу) не оценивалось; автоматически — только распознавание Yandex STT и косинусы.
- Акт 2 целиком на роботе с новой таблицей не гонялся.
- Не повлияло, но зафиксировано: инцидент с боевой БД (ниже).
