# Каст голосов ролей по эмбеддингам живого канала (#3992, эпик #3683)

Решение товарища Шифу 26.10: «для прогона надо чтобы голоса были разнесены по эмбеддингам далеко чтоб он не
путался»; переспрос «ты Саша?» отменён — различать должен сам каст. Раньше Шифу выбрал вариант Б: Гриша и Валера —
голоса другого регистра (женские или высокие), тексты реплик по роду. Эта редакция заменяет каст из
`role_voices_biometrics_2026-10-23.md` (там четыре низких мужских Russian_* склеивались в одного человека, 0.9).

## Коротко (честный итог)

- **Каст подобран и разнесён куда лучше прежнего, но строгий критерий «чужие по максимуму < 0.72» НЕ достигнут.**
  Худшие пары по максимуму среди всех пар записей: Саша–Борис **0.758**, Гриша–Валера 0.738, Борис–Гриша 0.737.
  Цель ≤ 0.65 по максимуму не достигнута ни у одной пары (ближе всех Саша–Гриша 0.656 и Борис–Валера 0.663).
- По более устойчивой мере каст проходит: p95 по парам записей ≤ 0.70, доля пар записей выше порога опознания 0.72
  — 0…2.7 % (у прежнего каста 97…100 % у трёх пар). Медианы чужих 0.52…0.62.
- **Сам `speaker_id_node` (боевой код, e2e-база) на 28 фразах четырёх голосов завёл ровно 4 профиля и ни разу
  не склеил два голоса** (26 решений; лучший счёт своего профиля 0.81…0.96, второй по счёту ≤ 0.68).
- Свой к своей (профиль 5 фраз → тест остальные): медиана 0.88…0.95, минимум 0.79…0.92 (цель ≥ 0.80: у Гриши
  один тест 0.787, у Бориса 0.811).
- **Вейк** (HIT = `ПРИНЯТО (respeaker)` без `[backlog] … no_wake`): 76 из 84 = 90.5 % суммарно; по ролям Саша 21/21,
  Гриша 20/21, Борис 18/21 (86 %), **Валера 17/21 (81 % — ниже цели 85 %)**. У Валеры во всех сценариях реплики БЕЗ
  «Робот,» (фон акта 3), так что на прогон это не влияет; два из четырёх промахов Валеры — не промах вейка, а
  чужой звук в окне (см. «Как мерили»).
- **Yandex и Silero каста не дают**: на этом канале голоса одного регистра дают 0.8–0.9 при любом провайдере.
  Четвёрка Yandex anton/ermil/zahar/filipp: 0.84–0.92 (81–100 % пар выше порога). Лучшая четвёрка из одного Yandex —
  худшая пара 0.80. Поэтому марафон обязан идти с `tts_provider=minimax`: при дефолте `auto` первым пробуется
  Yandex (он снова жив) и роли снова склеятся.
- Два запасных голоса **не получились**: старые (presenter_female, Russian_PessimisticGirl) склеиваются с новым
  Гришей (0.82–0.84); новый кандидат Portuguese_StrictBoss на границе (0.69–0.73, вейк не мерили), второго нет.

## Как мерили

Канал как у харнесса: wav → `highpass=f=100,volume=3.0,alimiter=limit=0.98,adelay=1500|all=1`, 16 кГц mono →
`pactl set-sink-volume 100%` → `paplay` на колонке katana → воздух → ReSpeaker → `/audio/speech_audio`. Запись
`/audio/speech_audio` — одноразовым контейнером `docker run --rm --network host` из образа voice-assistant
(`scripts/ros1.sh`, ros2 CLI внутри сервисных контейнеров не запускался). Эмбеддинг — resemblyzer тем же кодом,
что `SpeakerDatabase.embed_audio_ex` (`preprocess_wav` + `VoiceEncoder.embed_utterance`). Привязка проигрыша к записи
как 23.10: первая запись в окне `[t_start, t_end+9]`, длительность ±3 с от eq-файла.

- **Старые записи 23.10 использованы, не перемерены** (по уточнению Шифу): 206 записей из 254 проигрышей
  (`data/emb_2026-10-23.json`), матрица считается вместе с новыми (`scripts/analyze26.py`). Новые голоса мерились
  заново: 76 кандидатов (16 Yandex, 5 Silero v4 с новыми фразами, 55 MiniMax) и финалисты в комбинации.
- **Робот отвечает на каждую фразу с «Робот,»** (его реплика 11–13 с). Раньше следующая фраза налезала на хвост
  ответа и попадала в запись. Теперь после каждого проигрыша `robot_wait` ждёт по логу `TTS finished event`
  (фразы-«геометрия» без «Робот,» — `phrases_nw.json` — робот не отвечает и ждать не надо).
- **Фразы без представлений** (`phrases.json`, `phrases_nw.json`): вопросы к роботу, никаких «я …», «меня зовут …»,
  «я твой инженер» — после инцидента 23.10 с боевой базой.
- **Чистка ошибочных привязок.** Запись, у которой cos к центроиду своего голоса < 0.6 (при ≥ 8 записях у голоса),
  исключается и печатается. Исключена одна: `m-en_WhisperingGirl_p06` (0.499) — в окно попала речь самого робота
  («могу только свои электронные сигналы эмоции»), шёпот в этот раз VAD не поднял. До чистки и до повторного
  проигрыша трёх «первых» фраз такие мусорные записи давали ложное «Гриша–Валера 0.862»; без чистки
  (`VP26_RAW=1`) цифры лежат рядом в выводе скрипта. Повторные проигрыши (`playlog_e1`) заменяют первые
  (последний по времени на id).
- **Критерии** по метрике «профиль 5 фраз → тест остальные, cos = макс по профилю» (как у `identify`) **и** по всем
  парам записей A×B (строже). Порог опознания 0.72 не трогали.

## Что искали и что отвергнуто

Подбор шёл воронкой, все сырые цифры — в `results/screen_all_voices.txt`, `results/best_quartets_*.txt`:

1. **Yandex через ключ робота** (изнутри контейнера voice-assistant, ключ наружу не выносился): работают 16 голосов
   (anton, ermil, zahar, filipp, madirus, kirill, alexander, dasha, julia, lera, masha, marina, madi_ru, saule_ru,
   zhanar_ru, yulduz_ru); `kostya`, `rush`, `arina`, `nick` отвечают `PERMISSION_DENIED … Feature permission denied
   model=general` (сырой ответ в `logs/synth_raw.txt`). Мужские Yandex между собой 0.84–0.92, женские 0.80–0.92
   (`results/stats_yandex_females.txt`); `madirus` и `madi_ru` — один голос (0.993). Четвёрку Yandex не собрать
   (лучшая четвёрка по худшей паре 0.80).
2. **Silero v4** (aidar, eugene, kseniya, xenia, baya; по 7–17 записей): та же картина (aidar×eugene 0.87, baya×kseniya
   0.91). Одна Silero в связке с MiniMax даёт лучшую четвёрку 0.718 (`cute_boy, baya, Arnold, ColdYoungMan`), но это
   детский голос и потребовало бы провайдера на роль.
3. **MiniMax**: 332 системных голоса, русских 8; но речь на русском тянет любой голос, STT его понимает. Воронка:
   55 голосов по 2 фразы → около 20 финалистов по 8–10 → 4 голоса в комбинации. Лучше всего «разносят» голоса необычного
   регистра: шёпот (`Whispering_girl`), пожилой женский (`Gentle_Senior`), «учёный» и «весёлый» мужские. Оговорка:
   максимум по парам растёт с числом записей, а у кандидатов с 2 записями он занижен — у голосов с n=2 первый «победитель»
   (`WiseScholar` 0.66) на 22 записях оказался 0.76; кандидатов сравнивали и по p95 (`scripts/best_p95_26.py`).
4. **Питч/темп** как средство разведения — не использовались (23.10 опровергнуто).

## Что НЕ достигнуто и варианты (решать координатору и Шифу)

- Строгий критерий «макс < 0.72» не выполнен у трёх пар (Саша–Борис 0.758, Гриша–Валера 0.738, Борис–Гриша 0.737). Сильная
  сторона каста — доля пар выше 0.72 ≤ 2.7 % и 0 склеек у самого робота; риск: изредка первая фраза нового голоса
  (≈ 1–3 %) прилипнет к чужому профилю (порог слияния 0.75, опознания 0.72).
- Кандидат лучше по максимуму — `ko_ColdYoungMan, pl_MaleNarrator, Whisper, es_HumorousElder`: макс 0.709, p95 0.671,
  но 3 мужских голоса (Гриша тоже мужчина — правок по роду почти нет), по 8–10 записей, **вейк не мерили** (бюджет
  MiniMax на этом закончился: 286 из 300). Мерить: ≈ 42 синтеза «Робот, …» и 15–20 мин стенда.
- Валера-шёпот: вейк 81 %. Для сценариев не критично (его реплики без «Робот,»), но шёпот — самый хрупкий голос
  по STT. Если Шифу нужно «нормальное звучание» — заменить на `pt_StrictBoss` (0.69–0.73 к ролям, не мерен по вейку).
- Дефолт `tts_provider=auto` пробует Yandex первым: при живом Yandex многоролевые акты (2, 2b, 2c, 3) пойдут на
  Yandex и склеятся. Нужен явный `minimax` (или гард в харнессе) — отдельная карточка.
- Гард ADR-0134 (`gen_night_marathon._validate_voice_distinctness`) читает устаревший файл замера 22.09
  (`evidence/tts-voice-distinctness-2026-09-22/`, по файлам, не по живому каналу) — он этих цифр не видит; живой
  замер туда не заносился (завести файл — отдельное решение: порог в гарде по максимуму, а каст его строго не проходит).
