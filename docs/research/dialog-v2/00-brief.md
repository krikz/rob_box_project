# Бриф: ADR нового витка диалоговой системы (dialog v2)

Дата: 01.10.2026. База: `origin/develop` @ `61fd84ff7`.

## Зачем

Диалоговый ассистент робота (вход по wake-слову «Робби» → STT → диктор/лицо → LLM → тулы →
ответ → TTS, плюс перебивание, тишина, персоны, Telegram, avatar-supervisor) год чинили
заплатками по кругу. `dialogue_node.py` вырос до 9 954 строк при 353 fix-коммитах из 526.
У `DialogueNode` WMC 1 103 при лимите 80. Регексы по тексту ответа и синтетические ретраи
дают до 27 вызовов LLM на одну фразу. Фразу об успехе строит LLM. У состояния нет владельцев,
`architecture/ownership.yml` пуст.

Музыке уже выписали новый виток: [ADR-0149](../../adr/0149-arranger-v2-dj-engine.md), эпик
#3312, его сейчас исполняет другая сессия. Нужен такой же виток для **диалоговой системы
целиком**. Музыка в ней — одна подсистема-исполнитель: её интерфейс с диалогом в ADR
описывается, её устройство — нет.

## Принцип

[ADR-0148 «Код решает, LLM говорит»](../../adr/0148-code-decides-llm-speaks.md) — обязательное
основание. Новый ADR — его дизайн для диалога, так же как ADR-0149 — его дизайн для музыки.

- Культура честности (`AGENTS.md`): не выдавай непроверенное за проверенное.
