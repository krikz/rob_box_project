## Карточка A — куда переезжают инварианты `music_skill_prompt.txt`

**Откуда:** задача 6.2 change'а `skill-scoped-dialogue-context`, закрыта
частично.

**Факт.** `src/rob_box_voice/prompts/skills/music_skill_prompt.txt` —
87 999 байт (≈27 200 tok). В рантайм он **не грузится ни одной строкой**:
единственное чтение промптов в ноде — `_load_system_prompt`
(мастер-промпт) и `_load_skill_prompts` (`prompts/skills/<имя скилла>.txt`,
имя `music_skill_prompt` ни одному скиллу каталога не соответствует).
Удалить его как мёртвый файл нельзя: на нём висят **шесть** тестовых
файлов, и они проверяют не «текст на месте», а настоящие инварианты
рантайма.

Кто на нём висит:

| файл | что проверяет |
|------|---------------|
| `test_music_runtime_assets.py` | структура Stranger Things, Imperial March на SC-only синтах, запрет d4/d5/p4/p5 и случайных сэмплов, безопасность `tb303`, `estimate_tts_duration` |
| `test_synth_palette_is_preloaded.py` | каждый синт, объявленный в промпте, реально предзагружен в `foxdot_init` |
| `test_known_melody_library_1810.py` | библиотека известных мелодий (#1810) |
| `test_generate_music_is_gone.py` | промпт не приказывает мёртвый `generate_music` (#1403) |
| `test_issue_1392_v3_tool_order.py` | DJ MODE, MiniMax rate-limit / 429, enum анимаций, плейсхолдер `{renardo_ref}` |
| `test_prompt_animation_enum.py` | enum анимаций совпадает с каталогом |

**Почему это не «удалить и забыть».** Часть проверок — про файлы, а не про
текст: `test_synth_palette_is_preloaded` сверяет палитру синтов из промпта
с тем, что предзагружает `foxdot_init`; удалив промпт, мы теряем ЛЕВУЮ
часть сверки, и разъехавшийся синт снова полезет наружу на живом роботе
(это и был класс инцидента, ради которого тест писали). Второй части
(рецепты аранжировок Stranger Things / Imperial March) нет ни в каталоге
инструментов, ни в кратком `composer.txt`, ни в §5 мастер-промпта.

**Что решить в карточке (это и есть работа):**

1. Палитра синтов и runtime-ассеты. Кандидат: перенести объявление палитры
   в код рядом с `foxdot_init` (или в данные, которые он читает) и
   перенацелить `test_synth_palette_is_preloaded` на этот источник — тогда
   сверка станет «код против кода», без промпта посередине.
2. Рецепты аранжировок (Stranger Things, Imperial March, библиотека
   мелодий #1810). Либо это часть фрагмента скилла `composer` — тогда они
   должны быть краткими, иначе диета Move A теряет смысл; либо это
   справочник, который модель получает по запросу отдельным инструментом.
3. Правила, у которых уже есть близнец в мастер-промпте (d4/d5, `play("k")`,
   `tb303`, `estimate_tts_duration`): после фазы 5 они живут в секции
   `<<<SKILL-MOVE composer,dj>>>` и пришпилены тестами-близнецами на
   мастер-промпте. Здесь достаточно снять дублирующие проверки.
4. Только после 1-3 — удалить файл и снять с него оставшиеся тесты.

**Заодно (мелочь, но врёт):** комментарии в
`src/rob_box_voice/rob_box_voice/dialogue_node.py:325` и `:1062` всё ещё
описывают `music_skill_prompt.txt` как «static contract the LLM reads
verbatim at startup». Он не читается; проверка давно называется
`_validate_skill_fragments` и ходит по всем скиллам.

**Definition of done:** файла нет, ни один тест не потерян, каждый
инвариант из таблицы выше проверяется против источника, который реально
доезжает до робота.

## Карточка B — вынести `openai-agents` из образов

**Откуда:** задача 6.4 change'а, помечена «НЕ в этом change».

**Факт.** Зависимость стоит в двух requirements:

```
docker/vision/voice_assistant/requirements.txt:92  openai-agents>=0.19.4,<1.0.0
docker/vision/voice_base/requirements.txt:64       openai-agents>=0.19.4,<1.0.0
```

Импортов в репозитории после задачи 6.1 не осталось ни одного:
`grep -rn "^from agents\|^import agents" src/ docker/` пусто. Упоминания
`openai-agents`, которые остались, — это два комментария о том, что модуль
НЕ импортируется (`tool_registry.py:4`, `test_redact.py:145`).

Почему отдельной карточкой: это изменение образа, а не диалогового пути.
Едет своим PR со своей пересборкой и своим прогоном на роботе — размер
образа и время сборки надо померить до и после (ADR-0013 про размер PR).

**Definition of done:** строки убраны из обоих requirements, образ
пересобран, голосовой e2e прогнан на vision-pi, в карточке raw-вывод
`docker images` до/после и последние 50 строк `docker logs`.
