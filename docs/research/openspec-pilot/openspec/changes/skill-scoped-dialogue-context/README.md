# skill-scoped-dialogue-context

Доменные скиллы для диалоговой LLM робота.

**Суть:** сейчас ~27 100 токенов статического префикса (16 240 — схемы
54 инструментов, 10 838 — мастер-промпт) стоят на позиции 0, перед двадцатью
ходами истории. Инструкция «как пользоваться инструментом» физически удалена
от момента, когда она нужна. Скилл доставляет доменные инструкции **свежими,
вплотную к текущему ходу**.

Разделено на два независимых движения:

- **Move A (свежесть)** — фрагмент инструкций в хвост `messages`.
  `tools=` не трогаем, prefix-cache провайдера цел. Аддитивно, обратимо.
- **Move B (диета)** — сужение `tools=` до активного скилла. За флагом,
  по умолчанию выключено, включается только по метрикам.

Перед обоими — **фаза 0**: экспорт `prompt_tokens` в Prometheus. Сейчас
метрик по размеру промпта нет вообще, поэтому «стало лучше» нечем доказать
(ADR-0018).

**Явные non-goals:** возврат `openai-agents` SDK на диалоговый путь,
sub-агенты и handoff'ы, `@function_tool`-обёртки. Разбор — `design.md`
§Decisions.1 и §Decisions.4.

Связанные: ADR-0038 (adopt OpenSpec), ADR-0018 (честный FAIL), `e96b912d`
(удаление Compositor), issue #1403, #1544, #1708, #1777.
