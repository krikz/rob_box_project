```python
def title_prefix(t, n):
    s = (t or "").lower()
    tokens = re.findall(r"[\w]+", s, flags=re.UNICODE)
    return " ".join(tokens[:n])

def sorted_labels(issue):
    labels = issue.get("labels", []) or []
    names = []
    for lab in labels:
        if isinstance(lab, dict):
            n = lab.get("name", "")
        else:
            n = str(lab)
        if n:
            names.append(n)
    return ",".join(sorted(set(names)))
```

## Предлагаемый фикс (child-карточка t_235579f1)

Расширить group key в `dedup_intra_filter` (`agent-flow-triage.sh:870`)
дополнительным дискриминатором для deploy-bot issues — `deploy-signature`
из body:

```python
sig_match = re.search(r"deploy-signature:\s*(\S+)", (it.get("body") or ""))
sig = sig_match.group(1) if sig_match else "<none>"
key = sorted_labels(it) + "||" + title_prefix(it.get("title", ""), TITLE_WORDS) + "||deploy:" + sig
```

Это разнесёт #3346 (`deploy-fail:develop:staging:2026-10-02`) и #3354
(`deploy-fail:develop:staging:2026-10-03`) в разные группы, и каждое
deploy-fail событие получит свою карточку.

Детальный план + acceptance — в карточке `t_235579f1`.
