🧠 <b>«Код решает, LLM говорит»</b>

Если модель ошиблась на пути решения — переписала параметры, соврала об успехе, не вызвала инструмент, — мы чиним не уговорами в промпте. Решение уходит в код, а выбор модели сужается схемой.

Фразу об успехе строит код из результата выполнения, а не модель из головы. Принцип — ADR-0148 в репозитории; рядом правило нашей школы: честный FAIL лучше красивого PASS.
