# Набор для сторис Шифу (воронка подписчиков)

Публикует сам Шифу из своего аккаунта; бот сторис не трогает.

## Файлы

- `story.mp4` — вертикальное 1080×1920, 15–30 с, будет собрано из ролика Depot (`scripts/telegram/make_story.py --video … --start … --duration …`).
  Пока ролика нет, видео не собрано. Если файл тяжелее ~15 МБ, в репо он не лежит, только в scratchpad.
- `story-static.png` — статичная карточка 1080×1920 без кадра ролика (сейчас готова). После появления ролика
  пересобирается с кадром из него тем же скриптом.

## Что вставить в стикер-ссылку

1. В сторис Telegram: стикер «Ссылка» (Link) → вставить адрес.
2. До публикации поста: `https://t.me/robbox_project`.
3. После публикации поста с HIL-роликом: `https://t.me/robbox_project/<message_id>` — номер появляется в
   `docs/channel/queue/012-hil-depot.md` (поле `message_id`) после выхода поста.
4. Стикер поставить в нижнюю свободную зону (примерно нижние 420 px кадра), интерфейс сторис закрывает края.

## Подпись (одна, короткая)

> Это симуляция: как РОББОКС снимает карту склада. Рассказываем честно, что доехало, а что нет — в канале.

Подпись и строка-крючок на кадре должны совпадать с постом: если в итоговой сводке прогона не всё доехало, крючок не обещает «успех».
