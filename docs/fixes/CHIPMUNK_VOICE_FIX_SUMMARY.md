# Исправление голоса бурундука ROBBOX

## Проблема

После PR #87 робот говорил медленно и заторможенно, хотя эффект бурундука должен был быть восстановлен. Команды "говори выше/ниже" не работали - робот отвечал что не может изменить высоту голоса.

## Анализ оригинального кода

Изучив оригинальный рабочий скрипт ROBBOX (от 16.10.2025), обнаружена истинная причина эффекта бурундука:

```python
# Оригинальный код:
request = tts_pb2.UtteranceSynthesisRequest(
    hints=[
        tts_pb2.Hints(voice="anton"),
        tts_pb2.Hints(speed=0.4),  # ← Медленный синтез!
    ],
)

# Воспроизведение:
samples = np.frombuffer(audio_data, dtype=np.int16)  # ← Сырые байты БЕЗ декодирования WAV!
target_rate = 44100  # ← Частота звуковой карты
sd.play(samples, samplerate=target_rate)  # ← Воспроизведение на высокой частоте!
```

**Суть эффекта:**
1. Yandex TTS с `speed=0.4` генерирует медленное аудио на частоте ~22050 Hz
2. Аудио **не декодируется** - берутся сырые байты (включая WAV заголовок!)
3. Эти байты воспроизводятся на частоте 44100 Hz
4. **Результат: 44100/22050 = 2.0x** - голос выше и быстрее = бурундук!

## Решение

### Параметры по умолчанию (tts_node.py)

```python
self.declare_parameter("yandex_speed", 0.4)      # Медленный синтез (как в оригинале!)
self.declare_parameter("chipmunk_mode", True)    # Эффект всегда включён
self.declare_parameter("pitch_shift", 1.0)       # Базовый множитель
```

### Логика применения эффекта

```python
if self.chipmunk_mode:
    base_multiplier = 2.0  # Оригинальное соотношение 44100/22050
    effective_multiplier = base_multiplier * self.pitch_shift
    effective_rate = sample_rate / effective_multiplier
    
    # Двухэтапный resample для эмуляции оригинала:
    # 22050 Hz → 11025 Hz (эффективная) → 16000 Hz (ReSpeaker)
```

**Преимущества:**
- ✅ Работает с ReSpeaker (фиксированная частота 16kHz)
- ✅ Сохраняет оригинальный звук ROBBOX
- ✅ Позволяет регулировать высоту голоса

### Диапазоны управления pitch

- **Минимум:** `pitch_shift=0.5` → итоговый эффект 1.0x (лёгкий бурундук)
- **Стандарт:** `pitch_shift=1.0` → итоговый эффект 2.0x (оригинальный ROBBOX!)
- **Максимум:** `pitch_shift=2.0` → итоговый эффект 4.0x (очень высокий бурундук)

### Команды управления (dialogue_node.py)

**Высота голоса (pitch):**
- "говори выше" → `pitch_shift += 0.2` ✅
- "говори ниже" → `pitch_shift -= 0.2` ✅
- "нормальный голос" → `pitch_shift = 1.0` ✅

**Скорость речи (speed):**
- "быстрее" → `yandex_speed += 0.2` (макс 2.0)
- "медленнее" → `yandex_speed -= 0.2` (мин 0.5)
- "нормальная скорость" → `yandex_speed = 1.0`

## Техническая справка

### Почему pitch_shift=1.0, а не 2.0?

`pitch_shift` - это **дополнительный множитель** к базовому эффекту 2.0x:
- Базовый эффект: 2.0x (эмуляция 44100/22050)
- Итоговый эффект: `2.0 * pitch_shift`

Примеры:
- `pitch_shift=0.5` → 2.0 * 0.5 = 1.0x итоговый эффект
- `pitch_shift=1.0` → 2.0 * 1.0 = 2.0x итоговый эффект (оригинал!)
- `pitch_shift=1.5` → 2.0 * 1.5 = 3.0x итоговый эффект

### Почему yandex_speed=0.4?

В оригинальном скрипте используется `speed=0.4` для **медленного синтеза**. Это ключевая часть эффекта бурундука:
1. Медленный синтез → больше аудио данных
2. Быстрое воспроизведение → сжатие по времени
3. Результат → голос выше и быстрее

Если использовать `speed=1.0`, эффект будет слабее, так как меньше "материала" для ускорения.
