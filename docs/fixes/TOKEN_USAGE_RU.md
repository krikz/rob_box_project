# Логирование Использования Токенов - Краткая Инструкция

## Что Добавлено

В логи добавлена информация о потраченных токенах на вход (input) и выход (output) LLM.

## Формат Лога

### Обычный запрос
```
[dialogue_node] 📊 Token usage: input=142, output=67, total=209
```

### Рекурсивный запрос (с инструментами)
```
[dialogue_node] 📊 Token usage (recursive): input=1923, output=89, total=2012
```

## Как Использовать

### Извлечь данные из лога
```bash
grep "📊 Token usage" clog
```

### Подсчитать общие затраты

**1. Извлечь все записи:**
```bash
grep "📊 Token usage" clog > token_usage.txt
```

**2. Использовать Python скрипт:**
```python
import re

def analyze_token_costs(log_file):
    """Анализ затрат токенов из лога"""
    
    with open(log_file, 'r') as f:
        log_content = f.read()
    
    # Находим все записи о токенах
    pattern = r'📊 Token usage.*?: input=(\d+), output=(\d+), total=(\d+)'
    matches = re.findall(pattern, log_content)
    
    total_input = 0
    total_output = 0
    total_tokens = 0
    
    for match in matches:
        input_tokens, output_tokens, total = map(int, match)
        total_input += input_tokens
        total_output += output_tokens
        total_tokens += total
    
    # Цены DeepSeek (на миллион токенов)
    input_cost_per_1m = 0.14   # $0.14 за 1M входных токенов
    output_cost_per_1m = 0.28  # $0.28 за 1M выходных токенов
    
    input_cost = total_input * input_cost_per_1m / 1_000_000
    output_cost = total_output * output_cost_per_1m / 1_000_000
    total_cost = input_cost + output_cost
    
    print(f"Всего запросов: {len(matches)}")
    print(f"Всего входных токенов: {total_input:,}")
    print(f"Всего выходных токенов: {total_output:,}")
    print(f"Всего токенов: {total_tokens:,}")
    print(f"Стоимость входа: ${input_cost:.6f}")
    print(f"Стоимость выхода: ${output_cost:.6f}")
    print(f"Общая стоимость: ${total_cost:.6f}")

# Использование
analyze_token_costs('clog')
```

**3. Результат:**
```
Всего запросов: 15
Всего входных токенов: 12,450
Всего выходных токенов: 3,280
Всего токенов: 15,730
Стоимость входа: $0.001743
Стоимость выхода: $0.000918
Общая стоимость: $0.002661
```

## Расчет Стоимости Вручную

### Цены DeepSeek
- Вход (input): $0.14 за 1,000,000 токенов
- Выход (output): $0.28 за 1,000,000 токенов

### Пример расчета

**Лог:**
```
📊 Token usage: input=1842, output=89, total=1931
```

**Расчет:**
```
Вход:  1842 токена × $0.14 / 1,000,000 = $0.000258
Выход:   89 токенов × $0.28 / 1,000,000 = $0.000025
Итого:                                    $0.000283
```

## Что Означают Токены

### Input Tokens (Вход)
Размер промпта, который отправляется в LLM:
- Системный промпт
- История диалога
- Определения инструментов (если используются MCP tools)
- Результаты инструментов (в агентном цикле)

### Output Tokens (Выход)
Размер ответа LLM:
- Сгенерированный текст
- JSON вызовов инструментов (если LLM вызывает tools)

### Total Tokens (Всего)
Сумма: input + output

## Оптимизация Затрат

### Если много входных токенов (input)

**Причины:**
- Длинная история диалога
- Большой системный промпт
- Много определений инструментов
- Большие результаты от инструментов

**Решения:**
- Ограничить историю диалога (последние N сообщений)
- Упростить системный промпт
- Отправлять только нужные инструменты
- Сжимать описания результатов

### Если много выходных токенов (output)

**Причины:**
- Длинные ответы LLM
- Сложные вызовы инструментов
- Много инструментов за раз

**Решения:**
- Уменьшить max_tokens
- Просить более короткие ответы
- Оптимизировать промпт

## Мониторинг

### Проверить текущие затраты
```bash
# Последние 10 запросов
grep "📊 Token usage" clog | tail -n 10

# Самые "дорогие" запросы (по total)
grep "📊 Token usage" clog | \
  sed 's/.*total=\([0-9]*\).*/\1 &/' | \
  sort -rn | head -n 5
```

### Статистика за сессию
```bash
# Подсчитать средний размер
grep "📊 Token usage" clog | \
  grep -oP 'total=\K\d+' | \
  awk '{sum+=$1; count++} END {print "Average:", sum/count, "tokens"}'
```

### Сравнить обычные и рекурсивные
```bash
echo "Обычные запросы:"
grep "📊 Token usage:" clog | grep -v recursive | wc -l

echo "Рекурсивные запросы (с инструментами):"
grep "📊 Token usage (recursive)" clog | wc -l
```

## Типичные Значения

### Простой диалог (без инструментов)
```
Input:  100-300 токенов (промпт + история)
Output:  50-150 токенов (ответ)
Total:  150-450 токенов
```

### Диалог с инструментами
```
Input:  1500-2500 токенов (+ определения 17 инструментов)
Output:    30-100 токенов (вызовы инструментов в JSON)
Total:  1530-2600 токенов

Recursive Input:  1800-3000 токенов (+ результаты инструментов)
Recursive Output:   50-200 токенов (финальный ответ)
Recursive Total:  1850-3200 токенов
```

### Дневной бюджет

**Пример:** 1000 запросов в день
```
Средний размер: 2000 токенов
Средний input/output: 1500/500

Дневная стоимость:
Input:  1000 × 1500 × $0.14 / 1,000,000 = $0.21
Output: 1000 ×  500 × $0.28 / 1,000,000 = $0.14
Итого:                                    $0.35/день
Месяц:                                    $10.50/месяц
```

## Тревоги

### Когда беспокоиться

**🚨 Один запрос > 5000 токенов**
- Проверить: не зациклился ли агентный цикл?
- Проверить: не слишком ли длинная история?

**🚨 Дневные затраты > ожидаемых**
- Подсчитать количество запросов
- Найти "дорогие" запросы
- Оптимизировать промпт и инструменты

**🚨 Средний output > max_tokens**
- Обычно max_tokens=500
- Если average output близко к 500 - LLM обрезается
- Либо увеличить лимит, либо просить короче
