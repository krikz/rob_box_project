# Исправление джойнтов колес Rob Box

**Дата**: 2025-11-20  
**Проблема**: Колеса вращаются неправильно из-за несоответствия систем координат  
**Решение**: Вернуть поворот frame base_link и оригинальные позиции из Fusion 360  
**Статус**: ✅ ИСПРАВЛЕНО

---

## 🔍 Корневая причина

### Найденная проблема

В процессе адаптации модели робота была допущена ошибка:

1. **base_footprint_joint** был изменен с `rpy="0 0 -1.5708"` на `rpy="0 0 0"`
2. **Меши** были повернуты на `rpy="0 0 1.5708"` для компенсации
3. **Позиции колес и сенсоров** были пересчитаны для системы ROS
4. **НО оси колес** остались в системе Fusion 360

**Результат**: Несоответствие между позициями (пересчитаны) и осями (не пересчитаны)!

### Почему это проблема?

```
Frame base_link: система Fusion 360 (Y вперёд, X вправо)
Позиции колес: пересчитаны для ROS (X вперёд, Y влево)  
Оси колес: в системе Fusion 360 (вдоль X)

НЕСООТВЕТСТВИЕ! Позиции говорят "ROS", оси говорят "Fusion"
```

---

## 🔧 Решение

### Вариант А (ВЫБРАН): Вернуть поворот frame base_link

**Преимущества:**
- ✅ Оригинальные позиции из Fusion 360 (проверенные)
- ✅ Оригинальные оси из Fusion 360
- ✅ Всё согласовано, нет пересчётов
- ✅ Физический frame в системе ROS (X вперёд)

**Изменения:**

1. **base_footprint_joint** - вернуть поворот:
   ```xml
   <origin xyz="0 0 ${wheel_radius}" rpy="0 0 -1.5708"/>
   ```

2. **Меши** - убрать поворот (frame уже повернут):
   ```xml
   <origin xyz="0 0 0" rpy="0 0 0"/>
   ```

3. **Позиции колес** - вернуть оригинал Fusion 360:
   ```xml
   <!-- Левые -->
   origin_xyz="0.195 0.143797 0.028767"  <!-- было -0.143797 0.195 0.028767 -->
   
   <!-- Правые -->
   origin_xyz="-0.195967 -0.144669 0.0289"  <!-- было 0.144669 -0.195967 0.0289 -->
   ```

4. **Оси колес** - оставить как есть (Fusion 360):
   ```xml
   <!-- Левые -->
   axis_xyz="1.0 0.0 0.0"
   
   <!-- Правые -->
   axis_xyz="-1.0 0.0 0.0"
   ```

### Физический смысл

После исправления:

```
base_footprint (ROS frame: X вперёд, Y влево, Z вверх)
    └── base_link (повернут на -90° вокруг Z)
          └── система Fusion 360: Y вперёд, X вправо, Z вверх
```

**В системе Fusion 360:**
- Левые колеса находятся на +X (справа, если смотреть вдоль Y вперёд)
- Правые колеса находятся на -X (слева)
- Колеса вращаются вокруг оси X

**После поворота base_link на -90°:**
- Fusion Y → ROS X (вперёд)
- Fusion X → ROS Y (влево)
- Левые колеса (+X Fusion) → (+Y ROS) слева от центра ✅
- Правые колеса (-X Fusion) → (-Y ROS) справа от центра ✅
- Ось вращения X Fusion → ось Y ROS ✅
