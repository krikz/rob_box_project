## 🔧 Правильное решение (итоговое)

### Концепция

Оказалось, что в коммите 7686546:
- `base_footprint_joint` был БЕЗ ПОВОРОТА (rpy="0 0 0")
- Оси колес были `axis_xyz="1.0 0.0 0.0"` (Fusion 360)
- **И это работало правильно для корпуса!**

Проблема была не в осях колес, а в том что система координат Fusion 360 уже соответствует физическому роботу.

### Изменения

#### 1. base_footprint_joint (убрать поворот)

**Было (PR #234):**
```xml
<origin xyz="0 0 ${wheel_radius}" rpy="0 0 -1.5708"/>
```

**Стало:**
```xml
<origin xyz="0 0 ${wheel_radius}" rpy="0 0 0"/>
```

#### 2. Оси колес (оставить как в Fusion 360)

**Fusion 360 оси (правильные!):**
- Левые колеса: `axis_xyz="1.0 0.0 0.0"`
- Правые колеса: `axis_xyz="-1.0 0.0 0.0"`

**НЕ НУЖНО МЕНЯТЬ!** Эти оси правильные для корпуса робота.

#### 1. base_footprint_joint (строка 54-61)
```diff

+<!-- Джойнт base_footprint -> base_link БЕЗ ПОВОРОТА -->

 </joint>
```
