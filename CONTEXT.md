# CONTEXT — доменный словарь rob_box

Термины, которыми описывается система. Если код или документ называет вещь иначе —
расходится код или документ, не этот файл.

Заведён 2026-09-05 в ходе разбора архитектуры оператора и диалоговой ноды
(см. `docs/architecture/target-operator-agent-and-dialogue.md`).

---

## Агенты

**Личность** — агент, разговаривающий с людьми рядом с роботом. Живёт в
`dialogue_node`. Слышит только ReSpeaker. Отвечает через динамики робота.
Не знает ни о Quest, ни об операторе.
_Не путать_ с «диалоговой нодой»: нода — процесс, личность — роль внутри него.

**ТАРС** — агент-помощник оператора, он же супервизор (`avatar_supervisor`).
Позывной «ТАРС» — его вейк-слово. Слышит только микрофон шлема. Свои реплики
произносит **в наушники оператора**, не через динамики робота. Умеет всё, что
умеет личность, плюс операторское и административное.
_Не путать_ с «арбитром»: ТАРС решает, арбитр только выдаёт блокировки.

**Оператор** — человек в шлеме или в Telegram, управляющий роботом. Сейчас
идентифицируется парой `source` (`quest` / `telegram`) + `user_id`; в Quest
вход по 6-значному PIN.

**Арбитр** (`avatar_arbiter`) — нода без LLM, владеющая `LockManager` и FSM
режимов. Отвечает на сервисы floor быстрее 100 мс. Ни воли, ни состояния сверх
таблицы держателей: по смыслу ближе к мьютексу, чем к ноде принятия решений.

## Голос

**Пайплайн грипа** — путь речи оператора при зажатом левом грипе:
`STT → [LLM с пресетом | «Без стиля»] → TTS → динамики робота`. Прямоточный:
ноль или один вызов LLM, без инструментов и без истории. Конфигурируется
оператором в панели пайплайна. «Перевод» — один из пресетов, не отдельный режим.
_Не путать_ с ТАРС: пайплайн ничего не понимает, он трансформирует текст.

**Рация** — правый грип: звук с микрофона шлема играется динамиками робота
напрямую, без STT и без TTS.

**Вейк-слово** — слово, адресующее фразу агенту. Два namespace: личности
(«роббокс» + искажения STT) и оператора («ТАРС» + искажения). Namespace
привязан к **источнику аудио**, а не только к тексту: «ТАРС», сказанное в
ReSpeaker, не адресует ничего.

**Врезка** — постановка сегмента в голову очереди голосового канала вместо
хвоста. Исполняется после текущего чанка, не прерывая его. Механизм
подтверждений и операторской речи.

**Чанк** — единица синтеза `tts_node`. Границу чанка отмечает
`/voice/tts/batch_complete`. Естественная граница для врезки.

## Инструменты

**Каталог** — `rob_box_core.tool_catalog`, единственный источник схем
инструментов. Генерируется `tools/gen_tool_catalog.py`; править
`_tool_catalog_data.py` руками нельзя.

**Срез** (skill) — именованный список имён инструментов, которым сужается
каталог для конкретного агента. `core`, `personality.*`, `operator.speech`,
`operator.control`, `operator.admin`. Срез должен проверяться **на транспорте**,
а не только тем, какие схемы показали модели.

**`say`** — инструмент «заставить говорить **робота** вслух». Не путать с
собственной репликой ТАРС, которая звучит в шлеме.

## Движок

**AgentCore** — общий агентский движок обоих агентов: тул-цикл до 8 итераций,
окно истории, машина состояний, сужение до среза. Одно поведение, разная
конфигурация (промпт, срез, память, история). Происходит из `DialogCore`.
_Не путать_ с **Harness** — каркасом, который цикла не даёт и из которого
берутся только lifecycle, snapshot и конфиг.

**Журнал** — память ТАРС. Не история чата, а **лог изменений**: что сделал,
когда, чем кончилось. Сжимается схлопыванием повторов («перезапускал
`voice-assistant` 3 раза за час»), для хвоста старше суток — LLM-саммари.

**Планировщик** — `TaskScheduler`: единая точка прохождения tool-вызовов,
владеет каналами (voice, music, anim) и порядком внутри них. Сегодня подключена
только очередь; отмена (`EventBus`), рефлекс-слой и спекулятивная генерация
написаны, но не подключены.

**Канал** — очередь планировщика к одному ресурсу. Каналы независимы: движение
исполняется параллельно с речью.

## Блокировки

**Floor** — право на ресурс: `teleop_floor` (управление движением),
`voice_floor` (голосовой поток). Владелец — `LockManager` в арбитре, dead-man
500 мс. Всё остальное, что выглядит как floor (`ModeManager`, `VoiceFloor` в
quest-сервере, `SupervisorFloorTracker`), — кэш, а не источник правды.

**Режим** (`avatar_mode`) — `off` / `telegram_active` / `avatar_present` /
`mixed`. FSM режимов живёт в арбитре.

**Пауза** — состояние личности, в которое её переводит ТАРС командой
`/dialogue/control`. Срока не имеет; ТАРС напоминает голосом раз в 5 минут,
статус постоянно виден на мостике.

## Интерфейсы

**Мостик** (captain bridge) — 3D-сцена и панели в шлеме оператора.

**Панель пайплайна** — панель в шлеме, где оператор выбирает конфигурацию
пайплайна грипа: тумблеры STT/LLM/TTS, «Без стиля» и семь пресетов.
