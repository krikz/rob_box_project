## 🎯 О проекте

**РОББОКС** — образовательная платформа на базе автономного мобильного робота для практического изучения современных робототехнических технологий.

### Ключевые цели:

- 🎓 **Образовательная платформа** - практическое изучение ROS 2, компьютерного зрения, AI
- 🤖 **Автономная навигация** - самостоятельное перемещение в помещениях
- 💬 **Естественное взаимодействие** - голосовое управление с использованием LLM
- 📦 **Практическое применение** - доставка предметов как демонстрация возможностей

### Целевая функциональность:

- Дома и офисы - доставка документов, предметов
- Больницы - транспортировка материалов
- Гостиницы - обслуживание номеров
- Образование - учебная платформа для студентов

## ✅ Реализованные возможности

### 🗺️ Картографирование и локализация
- RGB-D камера + лазерный лидар для построения карты помещения
- RTAB-Map SLAM - одновременная локализация и картографирование
- 3D облако точек + 2D сетка занятости
- Оптимизация для работы на Raspberry Pi 5
- *Активное тестирование совместимости всех компонентов*

### 🚶 Автономная навигация
- Nav2 навигационный стек
- Планирование траектории с учётом динамических препятствий
- Колёсная одометрия от моторных контроллеров
- Избежание столкновений в реальном времени
- *Активное тестирование настройки и совместимости пакетов*
- *В процессе оптимизации: замена колёс для улучшения планирования*

### 💬 Голосовое взаимодействие
- Wake word detection (6 вариантов активации)
- Offline STT (Vosk) + TTS (Silero V4)
- Интеграция с облачными LLM (DeepSeek, Qwen)
- Offline fallback при недоступности облака
- Распознавание и выполнение команд навигации

### 💡 Визуальная обратная связь
- 381 адресуемый светодиод (NeoPixel LED)
- Композитор панелей для различных зон
- Анимации состояний и эмоций
- Синхронизация с голосовым ассистентом

### 📊 Мониторинг и телеметрия
- Grafana дашборды (20+ панелей мониторинга)
- Prometheus для сбора метрик
- Loki для централизованных логов
- Real-time наблюдение за состоянием систем
- Облачная интеграция через Zenoh

### 🏗️ Инфраструктура разработки
- CI/CD на базе GitHub Actions
- Локальная Build Machine (10-20x ускорение сборки)
- Docker микросервисная архитектура
- Автоматизированное развёртывание
- OTA обновления через Docker Registry

## 🔧 Технологический стек

### Платформа
- **ОС:** Ubuntu 24.04 Server
- **Робототехника:** ROS 2 kilted
- **Middleware:** Zenoh DDS
- **Контейнеризация:** Docker + Docker Compose

### Железо
- **Вычисления:** 2× Raspberry Pi 5 (16GB + 8GB)
- **Сенсоры:** LSLIDAR N10, OAK-D Lite, ReSpeaker Mic Array
- **Актуаторы:** 2× VESC моторные контроллеры, 381× NeoPixel LED
- **Связь:** Dual network (Gigabit Ethernet + WiFi)

### AI и NLP
- **LLM:** DeepSeek, Qwen (облачные + планируется self-hosted)
- **STT:** Vosk (offline)
- **TTS:** Silero V4
- **CV:** RTAB-Map, depthai, AprilTag
- **Планируется:** AI HAT с Hailo-8L NPU

### Навигация
- **SLAM:** RTAB-Map (RGB-D + 2D LiDAR), возможен ORB-SLAM3 для навигации по потолку
- **Path planning:** Nav2
- **Локализация:** AMCL (текущая), wheel odometry
- **Планируется:** переход на 3D локализацию при использовании стерео камеры, visual odometry, sensor fusion

### Инфраструктура
- **CI/CD:** GitHub Actions (→ self-hosted)
- **Мониторинг:** Grafana + Prometheus + Loki
- **Build:** Local Build Machine (APT cache, Docker registry)
- **Deployment:** Automated via workflows

## ❓ Часто задаваемые вопросы

**Это производственная система?**
Нет, это образовательный проект для изучения современного стека робототехнических технологий.

**Открытый код?**
Да, весь код открыт и доступен для изучения и модификации.

**Можно ли воспроизвести?**
Да, проект использует доступные компоненты. Вся документация публична.

**Стоимость реализации?**
Ориентировочно $2000-3000 для образовательной конфигурации (vs $20,000-50,000 для коммерческих аналогов).

**Временные рамки?**
- Базовая функциональность: реализована
- Полная функциональность: поэтапно до 2027 года

**Безопасность?**
Низкая скорость движения, активное избежание препятствий, множественные fail-safe механизмы.
